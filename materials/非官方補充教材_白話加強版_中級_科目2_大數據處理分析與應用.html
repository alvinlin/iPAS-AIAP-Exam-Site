第三章 機率統計基礎

💬 白話說資料再多，如果不會「看」，就只是一大堆數字。統計學給你三副眼鏡：敘述統計（這批資料長什麼樣？）、機率分佈（這種現象通常怎麼隨機變化？）、統計推論（從手上的樣本，能對全體說什麼？有多大把握？）。大數據時代這三件事一樣重要，甚至更容易被誤用（見 5.1）。

3.1 敘述性統計與資料摘要技術 完整教材 ↗

💬 白話說敘述統計就像幫一個班級寫「體檢摘要」：大家大概多高（集中趨勢）、高矮差多少（離散程度）、是不是大多數人擠在某一端或有幾個特別高的人（分佈形狀）。它只描述「手上這批資料」，不負責推論全國學生——那是 3.3 推論統計的工作。

（1）集中趨勢：五種「平均」各有用途

重點不是背公式，而是知道什麼情況該用哪一種。看下面三個小算例就懂了：

情境資料錯誤直覺正確做法
薪資有一位老闆3、3、4、4、5、5、6、100（萬）算術平均 = 130 ÷ 8 = 16.25 萬，「大家都月入 16 萬？」中位數 = (4+5)/2 = 4.5 萬，才代表「一般人」

看到「成長率、報酬率、連續相乘」想幾何；看到「速度、單位時間產量、油耗」想調和；看到「收入、房價、有極端值」想中位數；看到「顏色、品牌這類無法加減的類別」只能用眾數。

（2）離散程度：資料「擠不擠」

兩班平均都 70 分，A 班全員 68～72 分、B 班有人 30 分有人 100 分——平均一樣，但「波動」完全不同。變異數就是「每個值離平均多遠，平方後再平均」；開根號變回原單位就是標準差。

小算例：資料 2、4、4、4、5、5、7、9 → 平均 μ = 40/8 = 5；偏差平方和 = 9+1+1+1+0+0+4+16 = 32；母體變異數 σ² = 32/8 = 4；標準差 σ = 2

四分位數與箱形圖：把資料排好隊，切成四等份。Q1 是排在 25% 的人、Q2 是中間那位（中位數）、Q3 是排在 75% 的人。IQR = Q3 − Q1 就是「中間那一半人」的範圍，最不受頭尾極端值干擾。

箱形圖算例：Q1 = 20、Q3 = 40 → IQR = 20；下界 = 20 − 1.5×20 = −10、上界 = 40 + 1.5×20 = 70。資料中若有 85，就會被畫成鬚外的一個圓點（離群值）。

箱形圖本身的長相（下鬚、Q1、中位數、Q3、上鬚、鬚外圓點）可對照完整教材中引用的學習指引 3-8 頁附圖。

（3）分佈形狀：偏度與峰度

💬 白話說偏度看「尾巴拖向哪邊」：尾巴往右（高值）拖長叫右偏／正偏，典型是收入——大多數人普通，少數富豪把平均往右拉，所以右偏時平均數 > 中位數。尾巴往左拖叫左偏／負偏，如設備壽命大多很長、少數早夭。峰度看「尖頭重尾」：峰度大的分佈中間尖、尾巴厚，代表「平常很平靜，但偶爾出現極端大事」，金融報酬率就常是這樣，用常態分佈去估風險會低估崩盤機率。
🧠 記憶口訣偏度看尾巴，尾巴在哪邊就偏哪邊；平均跟著尾巴跑
右偏：眾數 < 中位數 < 平均數；左偏則反過來。峰度：「高峰重尾 >3、常態 =3、扁平 <3」（Pearson 定義）。
⚠️ 易混淆
  • 「峰度 3」還是「峰度 0」？指引採 Pearson 定義，常態分佈峰度 = 3（作答依此）。但 Python 的 pandas kurt()、SciPy 的 kurtosis() 預設輸出「超額峰度」（Excess Kurtosis，Fisher 定義 = Pearson − 3），常態分佈會顯示 0。實務看到軟體輸出 0.2 不代表「扁平」，要先確認定義。
  • 變異數除以 N 還是 n − 1？指引公式除以 N，是「母體變異數」。用樣本估計母體時，常除以 n − 1（樣本變異數），因為已用掉一個自由度去算樣本平均（見 3.2 自由度）。Excel 的 VAR.P 與 VAR.S 就是這兩種。
  • 箱形圖的「最大值」指不含離群值的鬚端，不一定是資料真正最大值；且箱形圖看不出多峰分佈。
📌 考試重點敘述統計目的是「概括並整理資料特徵」，不涉及推論；極端值多時以中位數代表集中趨勢；標準差衡量資料平均偏離中心的程度；IQR = Q3 − Q1，離群值界線為 Q1 − 1.5×IQR 與 Q3 + 1.5×IQR；正偏態（右偏）右尾長、偏度 > 0；峰度 > 3 為高峰（Leptokurtic）。

📖 名詞小辭典

敘述性統計Descriptive Statistics
把手上資料整理成幾個摘要數字或圖表，只描述、不推論。例：「本月客單價平均 350 元、中位數 280 元」。
推論統計Inferential Statistics
由樣本推估母體，並說明有多大把握（見 3.3）。例：抽 1,000 位選民推估全國支持率。
集中趨勢Central Tendency
資料「大致落在哪裡」的代表值，包括平均數、中位數、眾數。例：全班成績大約在 75 分附近。
算術平均數Arithmetic Mean
全部加總除以個數，最常用但會被極端值拉走。例：一位億萬富翁走進咖啡店，店內「平均財富」瞬間暴增。
幾何平均數Geometric Mean
n 個數相乘再開 n 次方根，適合連續相乘的成長率；資料必須都大於 0。例：基金三年報酬的「年化報酬率」。
調和平均數Harmonic Mean
個數除以「倒數總和」，適合速率類資料；不能有 0 或負值。機器學習的 F1-score 就是精確率與召回率的調和平均。例：來回同距離、不同時速的平均速度。
中位數Median
排序後正中間的值，不怕極端值。例：主計總處公布薪資時會同時給平均數與中位數。
眾數Mode
出現次數最多的值，唯一能用在類別資料的集中指標。例：手搖飲最多人點的甜度是「微糖」。
離散量度Variability / Dispersion
描述資料有多分散的指標：變異數、標準差、全距、IQR。例：兩家工廠螺絲平均長度相同，但一家誤差大得多。
變異數Variance
每個值與平均數差距的平方之平均；單位是原單位的平方。例：成績的變異數單位是「分²」，不好解讀，所以常再開根號。
標準差Standard Deviation, SD
變異數開根號，單位與原資料相同；越大越分散。例：股票日報酬標準差大＝波動大、風險高。
全距Range
最大值減最小值，最簡單但一個極端值就毀掉。例：今天氣溫 18～31 度，全距 13 度。
四分位數Quartiles (Q1, Q2, Q3)
把排序資料四等分的三個切點，Q2 就是中位數。例：Q1 = 30 歲表示 25% 會員年紀小於 30。
四分位距Interquartile Range, IQR
Q3 − Q1，中間 50% 資料的寬度，抗極端值。例：房價 IQR 小代表該區房價差異不大。
箱形圖（盒鬚圖）Box Plot / Box-and-Whisker Plot
用一個箱子加兩根鬚畫出 Q1、中位數、Q3 與離群值的圖。例：並排比較各門市客單價分佈。
鬚Whiskers
箱子上下延伸的線，最遠到 Q3 + 1.5×IQR 與 Q1 − 1.5×IQR 範圍內的最遠資料點。例：鬚外的點就是要特別檢查的值。
離群值（異常值）Outlier
明顯偏離大多數資料的值，可能是輸入錯誤，也可能是真實的罕見事件。例：體重欄出現 650 公斤。
探索性資料分析Exploratory Data Analysis, EDA
正式建模前，用摘要統計與圖表「先摸清資料脾氣」的階段。例：拿到新資料先畫直方圖、箱形圖、算缺失率。
偏度（偏態）Skewness
衡量分佈不對稱程度：> 0 右偏（右尾長）、< 0 左偏、≈ 0 對稱。例：網購訂單金額通常右偏。
峰度Kurtosis
衡量峰頂尖銳與尾部厚薄；Pearson 定義下常態 = 3。例：加密貨幣日報酬常是高峰重尾。
高峰／中峰／低峰（扁平）Leptokurtic / Mesokurtic / Platykurtic
峰度 > 3、≈ 3、< 3 的三種形狀。例：均勻分佈（擲公正骰子）屬扁平。
超額峰度Excess Kurtosis
Pearson 峰度減 3，使常態分佈為 0；許多統計軟體預設輸出這個。例：pandas 顯示 0.1 等於 Pearson 3.1。
🚀 延伸與新進展考試範圍外
  • 穩健統計量（1970 年代起）：除了中位數與 IQR，實務常用「截尾平均」（去掉頭尾各 5% 再平均，如體操評分去掉最高最低分）與 MAD（中位數絕對離差）。5.1 提到的製造業「MAD 法異常檢測」就是用它取代標準差，比 Z 分數更不怕被極端值帶歪。
  • 自動化 EDA 工具（2023）：指引 6.1 提到的 Pandas Profiling 已在 2023 年改名為 ydata-profiling，並加入 Spark 支援，一行指令就能產出含分佈、缺失率、相關係數、偏態警示的報表。
  • 大資料上的近似分位數（2013 年提出 t-digest）：資料大到無法排序時，Q1、Q3、中位數改用 t-digest 等「速寫」演算法估計，見 5.2。

3.2 機率分佈與資料分佈模型 完整教材 ↗

💬 白話說機率分佈是「隨機現象的說明書」：它列出所有可能結果，以及每種結果出現的機會。期望值是「玩很多次之後的長期平均」——擲骰子期望值 3.5，雖然你永遠擲不出 3.5；變異數是結果「忽高忽低」的程度。離散型像「數人頭」（0、1、2…個），用 PMF 直接說每個值的機率；連續型像「量身高」，任何單一精確值機率都是 0，只能問「落在某區間」的機率，所以用 PDF 曲線下的面積。
分佈一句話生活例子E(X)／Var(X)
伯努利丟一次銅板這位顧客會不會點廣告p／p(1−p)
二項丟 n 次銅板，數正面10 人看廣告，幾人點擊np／np(1−p)
泊松（卜瓦松）固定時段內「發生幾次」客服專線每小時來電數λ／λ
常態對稱鐘形，中間多兩邊少身高、量測誤差μ／σ²
指數「還要等多久」下一次發生兩通來電之間的間隔1/λ／1/λ²
卡方標準常態平方加總檢定用（不是描述日常現象）k／2k
算例①二項：廣告點擊率 p = 0.1，給 10 人看 → E = 10×0.1 = 1 人；Var = 10×0.1×0.9 = 0.9；P(沒人點) = 0.9¹⁰ ≈ 0.349
算例②泊松：每小時平均 3 通電話（λ = 3）→ P(這小時 0 通) = λ⁰e^(−λ)/0! = e^(−3) ≈ 0.050
算例③指數：同一條專線，平均等待下一通 = 1/λ = 1/3 小時 = 20 分鐘
💬 白話說：泊松與指數是一體兩面同一個「隨機來電」現象：問「一小時來幾通」用泊松（離散計數），問「下一通要等多久」用指數（連續時間）。指數分佈的無記憶性是說：已經等了 10 分鐘，接下來還要等的時間分佈跟剛開始一模一樣——不會因為等很久就「快來了」。這適合描述隨機故障，不適合會「老化」的零件（老化要改用 Weibull 分佈，指引也有提）。
💬 白話說：中央極限定理（CLT）不管原始資料長得多歪（例如右偏的訂單金額），只要每次抽夠多筆「算平均」，重複很多次後，這些平均值的分佈會接近常態鐘形。這就是為什麼許多檢定（t、z）能用在不太常態的原始資料上——因為檢定看的是平均數。但原始資料本身不會因此變常態。
🧠 記憶口訣一次伯努利、n 次二項、計次泊松、等候指數、平方卡方
再加一句：「泊松平均等於變異」（E = Var = λ）；「指數倒數」（E = 1/λ）；「卡方 k、2k」。
⚠️ 易混淆
  • 泊松公式的指數是 −λ：正確寫法 P(X=k) = λᵏ·e^(−λ) / k!（學習指引原文即為 e 的 −λ 次方）。常見筆誤是把指數寫成 −k，請記住指數是平均發生次數 λ，不是 k。
  • PMF vs PDF：PMF 的值本身就是機率（總和 = 1）；PDF 的值是「密度」可以大於 1，曲線下面積才是機率（總面積 = 1）。
  • 二項用常態近似需 np ≥ 5 且 n(1−p) ≥ 5，不是「n 大就好」。若計數資料變異數明顯大於平均數（過度離散），泊松不適用，可改用負二項分佈。
  • 中央極限定理講的是「樣本平均數的分佈」趨近常態，不是原始資料變常態。
💬 白話說：自由度三個數字平均要等於 10，你可以隨便選前兩個（例如 5 和 12），第三個就被迫等於 13——只有 2 個「自由」。算樣本標準差時先用掉樣本平均，所以自由度是 n − 1。自由度越大，t 分佈、卡方分佈越接近常態。
💬 白話說：分佈擬合就像替資料「挑一件最合身的衣服」：先看是計數（離散）還是量測（連續），再試穿幾個候選分佈，用最大似然估計（MLE）調參數——「哪組參數最可能產生我手上這批資料」——最後檢查假設（例如用自相關確認資料點彼此獨立）。
📌 考試重點二項分佈是典型離散型分佈；伯努利是二項在 n = 1 的特例；泊松 E = Var = λ，需事件獨立且發生率固定；常態由 μ、σ 決定；指數分佈描述等待時間、具無記憶性；卡方 E = k、Var = 2k，自由度增加趨近常態；中央極限定理指樣本平均數分佈趨近常態。

📖 名詞小辭典

隨機變數Random Variable
把隨機結果對應成數字的規則。例：X = 擲骰子出現的點數。
機率分佈Probability Distribution
列出隨機變數所有可能值與對應機率的函數。例：骰子每面機率都是 1/6。
期望值Expected Value, E(X)
以機率加權的平均，代表長期平均結果。例：彩券期望值通常小於票價，所以長期必虧。
離散型分佈Discrete Distribution
可能值可以一個個數出來（0、1、2…）。例：每日訂單數。
連續型分佈Continuous Distribution
可能值落在連續區間，任一點機率為 0，只能談區間機率。例：等公車的時間。
機率質量函數Probability Mass Function, PMF
離散型中，每個值剛好發生的機率；全部加起來 = 1。例：P(擲出 6) = 1/6。
機率密度函數Probability Density Function, PDF
連續型中描述機率「濃度」的曲線，區間下的面積才是機率。例：身高落在 170～175 公分的機率＝該段曲線下面積。
伯努利分佈Bernoulli Distribution
只做一次、只有成功／失敗兩種結果。例：一件產品合格與否。
二項分佈Binomial Distribution
n 次獨立、成功率固定的伯努利試驗中，成功的次數。例：寄 100 封 EDM 有幾封被打開。
組合數Combination, C(n,k)
從 n 個中選 k 個、不計順序的方法數 = n!/[k!(n−k)!]。例：10 人中挑 2 人有 45 種挑法。
泊松分佈（卜瓦松分佈）Poisson Distribution
固定時間或空間內，獨立事件以固定平均率 λ 發生的次數。例：某路口每天的事故數。
負二項分佈Negative Binomial Distribution
計數資料「變異數大於平均數」時，比泊松更合身的分佈。例：每位顧客的回購次數，少數人買超多。
常態分佈Normal / Gaussian Distribution
以平均 μ 為中心左右對稱的鐘形分佈；約 68% 落在 ±1σ、95% 在 ±2σ、99.7% 在 ±3σ。例：大量學生的身高。
中央極限定理Central Limit Theorem, CLT
樣本數夠大時，獨立同分佈變數的總和或平均數，其分佈趨近常態。例：單筆訂單金額很歪，但「每天 1,000 筆的平均金額」逐日看會接近鐘形。
獨立同分佈i.i.d., Independent and Identically Distributed
每筆資料彼此不影響、且來自同一個分佈；許多統計方法的前提。例：同一個人的多筆交易彼此相關，就不算獨立。
指數分佈Exponential Distribution
描述隨機事件之間的等待時間，平均 1/λ。例：網站兩次訪問之間的秒數。
無記憶性Memoryless Property
已經等了多久，不影響還要等多久的機率。例：隨機故障的設備，不會因為「已撐很久」就更快壞。
Weibull 分佈Weibull Distribution
可描述故障率會隨時間上升或下降的壽命分佈，是指數分佈的推廣。例：輪胎、軸承的老化壽命分析。
卡方分佈Chi-square Distribution, χ²
k 個標準常態變數平方的總和所形成的右偏分佈，主要用於檢定。例：卡方獨立性檢定的統計量就照它判斷。
自由度Degrees of Freedom, df
計算統計量時可以自由變動的資料點數。例：樣本標準差的自由度是 n − 1。
t 分佈Student's t Distribution
形狀像常態但尾巴較厚的分佈，小樣本、母體標準差未知時使用；自由度越大越接近常態。指引也把它列為重尾候選分佈。例：只有 15 筆樣本時估計平均數的信賴區間。
對數常態分佈Log-normal Distribution
取對數後呈常態的右偏分佈。例：所得、檔案大小、網頁停留時間。
重尾分佈Heavy-tailed Distribution
極端值出現機率比常態高得多的分佈。例：病毒式爆紅貼文的分享數。
分佈擬合Distribution Fitting
為資料挑選合適分佈並估計其參數。例：把每日故障次數擬合成 λ = 2.3 的泊松分佈。
最大似然估計Maximum Likelihood Estimation, MLE
選出「讓觀察到的資料出現機率最大」的參數值。例：100 次投籃進 62 球，MLE 估計命中率 0.62。
資料建模Data Modeling
把擬合好的分佈或模型用在預測、風險分析與決策。例：用來電分佈決定客服排班人數。
自相關Autocorrelation
同一序列與自己「過去值」的相關程度，用來檢查資料點是否獨立。例：今天銷量高、明天往往也高。
🚀 延伸與新進展考試範圍外
  • 機率式預測（Probabilistic Forecasting）（2024）：新一代時間序列基礎模型如 Amazon 的 Chronos（2024 年論文）會直接輸出「未來值的分佈」而不是單一數字，讓決策者看到 P10／P50／P90 等分位數，比只給點預測更能管理風險——正是本節「用分佈描述不確定性」的延伸。
  • 機率程式語言（Stan 2012 年起）：Stan、PyMC 等工具讓你直接寫出「資料是由什麼分佈產生」，由電腦自動估計參數與不確定性，是分佈擬合的進階版，常用於貝氏 A/B 測試（見 3.3）。

3.3 假設檢定與統計推論 完整教材 ↗

💬 白話說：法庭比喻假設檢定就像法院審判。虛無假設 H₀ = 被告無罪（現狀、沒差異、沒效果）；對立假設 H₁ = 有罪（你想證明的新主張）。檢察官（資料）要拿出夠強的證據，法官才判有罪（拒絕 H₀）。證據不足時判「無罪」，意思是「無法證明有罪」，不等於證明清白——所以統計上說「無法拒絕 H₀」，不說「接受 H₀」。

p 值：在「被告其實無辜」的世界裡，看到這麼誇張證據的機率

算例：懷疑一枚硬幣不公正。H₀：硬幣公正。丟 10 次出現 9 次正面。
若硬幣真的公正，出現「9 次或更多正面」的機率 = (C(10,9) + C(10,10)) / 2¹⁰ = 11/1024 ≈ 0.011；考慮「9 次以上反面」同樣極端（雙尾），p ≈ 0.021。
p = 0.021 < α = 0.05 → 拒絕 H₀：證據足以懷疑硬幣不公正。但若事先設定 α = 0.01，則無法拒絕。
⚠️ 易混淆：p 值「不是」什麼
  • p 值不是「H₀ 為真的機率」，也不是「結果是巧合的機率」。它是「假設 H₀ 為真時，看到這麼極端或更極端資料的機率」。
  • p 值小不代表效果大或有實務價值；樣本極大時，微小差異也會很顯著（見 5.1 p 值膨脹）。
  • α 是事前定好的門檻；p 是事後從資料算出來的。看到結果再調整 α 或改成單尾，是違規操作。

信賴區間：撒網的比喻

💬 白話說母體平均數是湖裡一條固定位置的魚，信賴區間是你撒出去的網。「95% 信賴區間」是說：用這種撒網方法撒 100 次，大約 95 次網裡會有魚。一旦網撒下去了，魚要嘛在網裡、要嘛不在，所以不能說「這張網有 95% 機率抓到魚」。
算例：抽 100 人，平均體重 68 公斤，母體標準差約 10 → 標準誤 SE = 10/√100 = 1
95% CI ≈ 68 ± 1.96 × 1 = [66.04, 69.96] ≈ [66, 70]（與指引表格例子一致）
樣本加到 400 人 → SE = 0.5，區間縮成約 [67, 69]：樣本越多，網越小越精準。

型一、型二錯誤：火災警報器

真實＼警報器沒響（保留 H₀）響了（拒絕 H₀）
沒失火（H₀ 真）正確型一錯誤：烤個吐司就狂響（誤報、偽陽性），機率 α
真的失火（H₀ 假）型二錯誤：失火卻沒響（漏報、偽陰性），機率 β正確偵測，機率 1 − β ＝ 檢定力
💬 白話說：兩種錯誤的蹺蹺板把警報器調得更不敏感（α 從 0.05 降到 0.01），誤報少了，但真失火時漏報（β）會變多。想兩種錯誤同時變少，唯一穩定的辦法是「更好的感測器」——在統計上就是增加樣本數（或降低雜訊）。檢定力分析就是事先算好「要多少樣本，才能有 80% 機率抓到我在乎的效果」。
🧠 記憶口訣一錯冤枉好人（α），二錯放走壞人（β）
型一：H₀ 是對的卻被拒絕（誤判、偽陽性）；型二：H₀ 是錯的卻沒拒絕（漏判、偽陰性）。「p 小拒 H₀」：p ≤ α 就拒絕。

各種檢定怎麼選：三個問題決定

  1. 比的是什麼？平均數（連續）／比例或次數（類別）／兩變數關聯。
  2. 幾組？是否同一批人？一組對已知值／兩組獨立／同一批前後測／三組以上。
  3. 資料常態嗎？有極端值嗎？是順序資料嗎？是 → 參數檢定；否 → 非參數替代。
情境參數檢定（常態）非參數替代生活例子
一組平均 vs 已知值單樣本 t（σ 已知用 Z）（符號檢定等，指引未列）這批咖啡豆平均重量是否真的 500 克
兩組獨立平均獨立樣本 t（變異數不等用 Welch）Mann-Whitney UA、B 兩分店客單價
同一批人前後成對樣本 t（Wilcoxon 符號等級，指引未列）同批員工受訓前後測驗分數

兩類別變數關聯卡方獨立性檢定（期望頻數 ≥ 5；強度看 Cramér's V）性別與偏好口味是否有關

非參數檢定的共同精神是「把數值換成名次再比較」，所以不怕極端值與非常態。
⚠️ 易混淆
  • 獨立 vs 成對：同一批人前後測一定用成對 t（看「差值」），用獨立 t 會浪費掉「同一個人」的資訊。
  • ANOVA 顯著只表示「至少有一組不同」，要再做事後檢定才知道是哪幾組。只有兩組時直接用 t 檢定。
  • 皮爾森 vs 斯皮爾曼：皮爾森只抓「直線」關係；斯皮爾曼抓「單調」關係（一個變大另一個也一路變大，不必是直線）。兩者顯著都不代表因果。
  • 卡方檢定要用原始次數，不能拿百分比代入；顯著也不代表關係強。
  • 單尾或雙尾要事先決定，不能看到結果再改。
📌 考試重點統計推論 = 參數估計（點估計、區間估計）＋ 假設檢定；檢定五步驟：定 H₀/H₁ → 選方法 → 定 α → 算統計量與 p → 決策；p ≤ α 拒絕 H₀，p > α 無法拒絕（不代表 H₀ 為真）；α 是型一錯誤上限，檢定力 = 1 − β；降低 α 會提高 β；多重比較以 Bonferroni 校正；σ 已知用 Z 檢定；變異數不等用 Welch；三組以上用 ANOVA 並做 Tukey HSD 事後檢定；非常態用 Mann-Whitney U（兩組）或 Kruskal-Wallis（三組以上）。

📖 名詞小辭典

統計推論Statistical Inference
用樣本對母體下結論，並量化不確定性。例：抽檢 200 瓶飲料推估整批的含糖量。
母體／樣本Population / Sample
母體是想了解的全體；樣本是實際蒐集到的一部分。例：全台上班族 vs 你問卷到的 800 人。
參數估計Parameter Estimation
推測母體參數（如平均數）的值或範圍。例：估計全台平均通勤時間約 40 分鐘。
點估計Point Estimation
用一個數字當最佳猜測，看不出把握有多大。例：「支持率 52%」。
區間估計／信賴區間Interval Estimation / Confidence Interval, CI
給一個範圍，並附上方法的可靠程度（信心水準）。例：「支持率 52%，95% CI 為 49%～55%」。
標準誤Standard Error, SE
樣本統計量（如樣本平均）的標準差，等於 σ/√n；樣本越大越小。例：樣本變 4 倍，標準誤減半。
假設檢定Hypothesis Testing
用資料判斷是否有足夠證據推翻「現狀假設」。例：新藥是否比安慰劑有效。
虛無假設Null Hypothesis, H₀
預設立場：沒差異、沒效果、維持現狀。例：新舊網頁轉換率相同。
對立假設Alternative Hypothesis, H₁
想證明的主張：有差異或有效果。例：新網頁轉換率比較高。
顯著水準Significance Level, α
事前設定、可容忍的型一錯誤機率上限，常用 0.05。例：藥物安全研究改用更嚴格的 0.01。
p 值p-value
假設 H₀ 為真時，得到「與實際樣本一樣或更極端」結果的機率。例：p = 0.03 表示「若真的沒差，這麼大的差距只有 3% 機會出現」。
檢定統計量Test Statistic
把樣本資訊濃縮成一個數（t、Z、F、χ²），再查對應分佈得到 p 值。例：t = 2.5。
型一錯誤Type I Error（偽陽性 False Positive）
H₀ 其實是對的，卻拒絕它；機率 = α。例：無效的新藥被誤判有效而核准。
型二錯誤Type II Error（偽陰性 False Negative）
H₀ 其實是錯的，卻沒拒絕它；機率 = β。例：真的有效的行銷方案被判「沒差」而放棄。
檢定力Statistical Power, 1 − β
真的有效果時，檢定能抓到它的機率；樣本大、效果大、雜訊小則檢定力高。例：實驗設計常要求檢定力 80%。
檢定力分析Power Analysis
事前計算達到目標檢定力所需的樣本數。例：A/B 測試前算出每組要 5,000 位使用者。
雙尾／左尾／右尾檢定Two-tailed / Left-tailed / Right-tailed Test
對立假設是「不等於」「小於」「大於」三種方向，須事先決定。例：只關心新製程是否「降低」不良率 → 左尾。
Z 檢定Z-test
母體標準差已知（或大樣本比例）時，以標準常態分佈判斷的檢定。例：雙樣本比例檢定常用 Z 統計量。
Z 分數Z-score
(x − μ)/σ，某值距離平均幾個標準差；|Z| ≥ 3 常視為異常。例：交易 3200、平均 2000、σ 400 → Z = 3。
單樣本 t 檢定One-sample t-test
樣本平均與某個已知值比較。例：包裝標示 500 克，抽 20 包檢驗。
獨立樣本 t 檢定Independent Samples t-test
兩組不同個體的平均比較。例：男、女顧客平均消費。
Welch t 檢定Welch's t-test
兩組變異數不相等時使用的獨立樣本 t 檢定修正版。例：大店與小店營收波動差很多時。
Levene 檢定／F 檢定Levene's Test / F-test
檢查兩組或多組變異數是否相等（變異數齊一性）。例：做 t 檢定前先確認兩組波動相近。
成對樣本 t 檢定Paired Samples t-test
同一個體兩種情況的差值是否為 0。例：同一批病人治療前後血壓。
單因子變異數分析One-way ANOVA
一次比較三組以上平均是否全部相等；用 F 統計量。例：北、中、南三區平均客單價。
事後檢定Post-hoc Test（Tukey HSD、Dunn's test）
ANOVA 或 Kruskal-Wallis 顯著後，找出到底哪幾組不同，並控制多重比較錯誤。例：發現北區與南區有差、中區與其他沒差。
比例檢定Proportion Test（One / Two-sample）
檢定一個比例是否等於某值，或兩個比例是否相同。例：新舊按鈕顏色的點擊率。
A/B 測試A/B Testing
把使用者隨機分成兩組，分別給 A、B 版本，比較指標差異的實驗。例：電商測試兩種結帳流程。
Fisher 精確檢定Fisher's Exact Test
樣本或事件數很少、不適合常態近似或卡方時的精確檢定。例：罕見副作用 3 例 vs 0 例。
卡方檢定Chi-square Test（獨立性、適合度、齊一性）
比較「觀察次數」與「預期次數」差多少，判斷類別變數是否相關或是否符合某分佈。例：年齡層與付款方式是否有關。
Cramér's VCramér's V
卡方檢定後衡量兩類別變數關聯「有多強」的指標，介於 0～1。例：V = 0.08 雖顯著但關聯很弱。
皮爾森相關係數Pearson Correlation, r
兩連續變數「直線關係」的方向與強度，−1 到 +1。例：氣溫與冰品銷量 r = 0.8。
斯皮爾曼等級相關Spearman's Rank Correlation, rs
用名次計算的相關，衡量單調關係，不需常態、不怕極端值。例：評審排名與觀眾排名是否一致。
單調關係Monotonic Relationship
一個變數增加時另一個一路增加（或一路減少），但不一定是直線。例：練習時數與熟練度，越後面進步越慢但仍在進步。
參數／非參數檢定Parametric / Non-parametric Test
參數檢定假設資料來自特定分佈（多為常態）；非參數檢定不依賴分佈假設，多用排名。例：滿意度 1～5 分的順序資料適合非參數法。
Mann-Whitney U 檢定Mann-Whitney U Test
兩獨立組的非參數比較（獨立樣本 t 的替代），比較排名分佈。例：兩家店的顧客評分（1～5 分）。
Kruskal-Wallis 檢定Kruskal-Wallis Test
三組以上獨立樣本的非參數比較（ANOVA 的替代）。例：三種客服管道的滿意度排名。
Friedman 檢定Friedman Test
同一批受試者在三種以上條件下的非參數比較（重複量數設計）。例：同批試吃者評比三種口味。
Bonferroni 校正Bonferroni Correction
同時做 m 次檢定時，把每次的門檻改成 α/m，控制「至少錯一次」的機率。例：做 10 次檢定，每次門檻 0.005。
🚀 延伸與新進展考試範圍外
  • 美國統計學會 p 值聲明（2016）：ASA 正式提醒 p 值不衡量效果大小、也不是假設為真的機率，科學結論不應只靠「p < 0.05」一刀切。業界因此普遍要求同時報告效果量（如 Cohen's d：兩組平均差除以標準差，0.2 小、0.5 中、0.8 大）與信賴區間——指引 5.1 也這麼建議。
  • Bootstrap 重抽樣（1979，Efron）：不想背公式、或統計量太複雜（如中位數的信賴區間）時，從樣本「有放回地」重抽上千次、每次算一次統計量，看它們的分佈就得到信賴區間。電腦夠快後成為資料科學標配，指引 5.1 提到它在大數據上的運算成本問題。
  • 貝氏 A/B 測試（2010 年代普及）：直接回答老闆真正想問的「B 比 A 好的機率是多少？」（例如 94%），而不是 p 值。它把事前知識（先驗）與資料結合，結果更直覺，但需謹慎選擇先驗。
  • CUPED 變異數縮減（2013，Microsoft 研究）：A/B 測試時用「實驗前的行為資料」扣掉個人差異，降低雜訊，等於不加樣本就提高檢定力，許多大型實驗平台採用。
  • 序貫檢定與「偷看」問題（2017，KDD 論文〈Peeking at A/B Tests〉）：A/B 測試每天看一次 p 值、一顯著就停，會大幅提高型一錯誤。序貫檢定方法允許持續監看而仍控制錯誤率，是線上實驗平台的標準功能。
  • 因果推論入門（2018，DoWhy／Double ML）：相關不等於因果。無法做隨機實驗時，可用傾向分數配對、差異中之差異（DiD）、雙重機器學習（Double ML，2018）等方法估計「因果效果」；Microsoft 的 DoWhy 套件把流程整理成「建模 → 識別 → 估計 → 反駁」四步。

第四章 大數據處理技術

💬 白話說資料從幾千筆變成幾十億筆，就像從「家裡煮一餐」變成「中央廚房每天出十萬份便當」：採買要有固定管道（收集）、食材要洗乾淨挑掉爛的（清理）、要有大型冷藏庫並分區擺放（儲存）、要很多廚師同時備料（分散式處理），還要一條自動化產線串起每一步（資料管線）。

4.2 數據儲存與管理 完整教材 ↗

💬 白話說關聯式資料庫像會計帳本：欄位固定、每筆都要對得上（ACID）；文件型 NoSQL 像資料夾：每份文件欄位可以不同；物件儲存像超大倉庫：什麼都能丟進去，用標籤（metadata）找。資料倉儲是「整理好上架的超市」，資料湖是「先全部倒進去的大水庫」，要用時再決定怎麼看（Schema-on-Read）；資料湖倉則是在水庫上加裝超市的貨架與收銀系統——既能便宜地存原始資料，又有交易保證與治理。
比較資料倉儲資料湖資料湖倉
結構寫入前先定義（Schema-on-Write）讀取時才套用（Schema-on-Read）開放表格式提供 schema 與演進
資料型態以結構化為主結構化＋半結構化＋非結構化同資料湖
交易保證有（ACID）通常沒有有（Delta Lake、Iceberg、Hudi）
風險彈性低、成本高沒治理會變「資料沼澤」架構較新，需選定表格式與目錄
💬 白話說：強一致 vs 最終一致銀行轉帳必須強一致——你轉出後，任何分行查都要立刻看到新餘額。社群按讚數可以最終一致——台北看到 101 讚、高雄暫時看到 99 讚沒關係，幾秒後會對齊，換來更快、更不容易當機。
🧠 記憶口訣ACID：全有全無、前後一致、互不干擾、存了不掉
原子性（Atomicity）、一致性（Consistency）、隔離性（Isolation）、持久性（Durability）。存取控管四模型：RBAC 看「角色」、ABAC 看「屬性」、PBAC 看「策略」、DAC 看「擁有者自己決定」。
💬 白話說：查詢加速招式分區＝檔案櫃依年月分抽屜，查 3 月只開 3 月那格；列式儲存（Parquet、ORC）＝把同一欄的資料放在一起，只算「金額」時不必讀整列；欄位裁剪＝只拿需要的欄；物化檢視＝把常問的答案先算好貼在牆上；儲存分層＝常用的放手邊（SSD，熱資料）、少用的放倉庫（HDD／雲端封存，冷資料）。
⚠️ 易混淆
  • ACID 的 C（一致性）≠ 分散式系統的「強一致性」：前者指交易前後符合資料規則（例如帳戶總額不變）；後者指各節點副本何時看到同樣的最新值。
  • Schema-on-Read（資料湖）vs Schema-on-Write（倉儲）：前者讀的時候才解釋結構，後者寫入就要符合表格定義。
  • RBAC vs ABAC：「工程師角色可讀」是 RBAC；「台北分公司、上班時間、公司設備才能讀」是 ABAC。
📌 考試重點半結構化 JSON/XML 適合文件型 NoSQL；分散式儲存核心是跨節點切分與冗餘備援（橫向擴充、多副本、Paxos/Raft）；資料湖支援多樣型態、不需預先定義結構（Schema-on-Read）；資料湖倉結合湖的彈性與倉儲的治理；ACID 四特性；強一致性適合金融交易、最終一致性適合大型物件儲存；Delta Lake Time Travel 支援版本回溯與可重現性；零信任強調最小權限、持續驗證。

在資料湖上加入交易、schema、治理能力的架構。例：S3 上的 Parquet 檔透過 Iceberg 表格式當成資料表查詢。
開放表格式Open Table Format（Delta Lake、Apache Iceberg、Apache Hudi）
在一堆資料檔之上加一層「交易日誌／中繼資料」，讓它們表現得像一張可更新、可回溯的資料表。例：Iceberg 表可以安全地同時寫入與查詢。
列式儲存格式Columnar Format（Parquet、ORC）
同一欄資料存放在一起，壓縮率高、只讀需要的欄很快。例：只算平均金額時，不必讀地址欄。
AvroApache Avro
以列為單位、內含 schema 的二進位格式，常用於串流訊息與資料交換。例：Kafka 訊息常用 Avro 編碼。
分區儲存Partitioning
依時間、地區等欄位把資料水平切開存放，查詢只掃需要的分區。例：依「年/月/日」資料夾存日誌。
分片Sharding
把資料庫資料水平拆到多台伺服器，分攤負載。例：會員依 ID 尾數分到 10 台資料庫。
壓縮演算法Compression（Snappy、ZSTD）
縮小檔案以省空間與 I/O；Snappy 快、ZSTD 壓縮率較高。例：日誌壓縮後只剩原本的 1/5。
儲存分層Storage Tiering
依使用頻率把資料放在不同成本的儲存媒介。例：近 30 天放 SSD，三年前的放封存儲存。
欄位裁剪Column Pruning / Projection
查詢時只讀取需要的欄位。例：SELECT 金額，而不是 SELECT *。
物化檢視Materialized View
把查詢結果預先算好存起來，下次直接取用。例：每小時更新一次「各店當日營收」表。
倒排索引Inverted Index
記錄「每個詞出現在哪些文件」的索引，搜尋引擎的核心。例：搜尋「退貨」立刻找出所有含此詞的客服紀錄。
查詢最佳化器Query Optimizer（Spark Catalyst、Presto CBO）
自動決定最省成本的查詢執行方式；CBO 為成本導向最佳化器（Cost-Based Optimizer）。例：先過濾再關聯，而不是先關聯再過濾。
強一致性／最終一致性Strong / Eventual Consistency
寫入後所有讀取立刻看到最新值／短時間內可能不同，但最終會一致。例：轉帳餘額／按讚數。
ACIDAtomicity, Consistency, Isolation, Durability
交易的四大保證：原子性、一致性、隔離性、持久性。例：轉帳時扣款與入帳必須同時成功或同時取消。
時間旅行（版本回溯）Time Travel / Snapshot
查詢資料表在過去某個版本的內容。例：重現上個月訓練模型時用的那份資料。
增量查詢Incremental Query（Apache Hudi）
只取出某時間點之後變動的資料。例：每 10 分鐘只同步新增或修改的訂單。
可重現性Reproducibility
用同樣資料與程式能得到同樣結果的能力。例：稽核時能重跑出當初的模型分數。
元資料（中繼資料）Metadata
描述資料的資料：來源、格式、欄位意義、更新時間、擁有者。例：照片的拍攝時間與 GPS。
資料目錄Data Catalog
全公司資料的「圖書館目錄」，可搜尋有哪些資料、意義為何、誰負責。例：搜尋「營收」找到正確的官方報表表格。
資料血緣Data Lineage
追蹤資料從哪裡來、經過哪些轉換、流到哪裡。例：報表數字錯了，往回查是哪個上游表出問題。
RBAC／ABAC／PBAC／DACRole- / Attribute- / Policy-Based / Discretionary Access Control
依角色／依屬性與環境條件／依集中定義的策略規則／由資料擁有者自行授權的存取控管方式。例：分析師角色可讀銷售表（RBAC）。
OPA／RegoOpen Policy Agent / Rego
開源的通用策略引擎與其策略語言，把授權規則寫成程式統一管理。例：多個雲端服務共用同一套存取規則。
存取稽核Access Audit / Audit Log
記錄誰、何時、從哪台設備、做了什麼操作。例：查出是誰下載了整份客戶名單。
零信任Zero Trust
不因為「在公司內網」就信任，每次存取都要驗證身分與權限。例：員工在辦公室連內部系統也要多因素驗證。
最小權限原則Least Privilege
只給完成工作所需的最少權限。例：客服只能看客戶電話後四碼。
即時授權Just-In-Time Access
需要時才臨時開權限、用完自動收回。例：工程師緊急維修時申請 2 小時的資料庫權限。
持續驗證Continuous Authentication
登入後仍持續依行為、裝置、位置判斷是否可信。例：半夜從國外登入就要求重新驗證。
微分段Microsegmentation
把網路與資源切成很小的區塊各自防護，一處被入侵不會全面淪陷。例：資料庫伺服器只允許特定應用程式連線。
🚀 延伸與新進展考試範圍外
  • 表格式之爭走向互通（2024）：2024 年 6 月 Databricks 宣布收購由 Iceberg 原創者創立的 Tabular，目標讓 Delta Lake 與 Iceberg 互通；同月 Databricks 也將 Unity Catalog 以 Apache 2.0 授權開源並交由 LF AI & Data 託管，支援 Iceberg REST Catalog 介面。意義：指引列的三種開放表格式不再是「只能選一個」。
  • Apache Iceberg v3（2025）：新規格加入「刪除向量」（以位元圖標記被刪除的列，不必重寫整個檔案）與 Variant 型別（存放半結構化 JSON 類資料），讓資料湖倉處理更新與半結構化資料更有效率。
  • 雲端原生「表格桶」（2024）：AWS 於 2024 年 12 月推出 Amazon S3 Tables，在物件儲存層直接提供受管的 Iceberg 資料表與自動維護，物件儲存與湖倉的界線更模糊。
  • DuckLake（2025）：DuckDB 團隊 2025 年 5 月提出的湖倉格式，資料檔仍是 Parquet，但把中繼資料改存在一般 SQL 資料庫中（而非一堆中繼資料檔），2026 年 4 月發布 1.0。顯示「中繼資料怎麼管」仍在快速演進。
  • 向量資料庫與向量儲存（2025）：為了生成式 AI 的語意檢索（見 6.3），出現專門存放「嵌入向量」並支援相似度搜尋的系統；連物件儲存都加入此功能，如 Amazon S3 Vectors（2025 年 7 月預覽、12 月正式推出）。這是指引三種資料型態之外、AI 時代新增的「第四種」儲存需求。

⚠️ 易混淆
  • 標準化 vs 正規化：指引中 Z-score 稱標準化（平均 0、標準差 1）、Min-Max 稱正規化（縮到 0～1）。注意：深度學習裡的「Batch Normalization」與這裡的資料前處理是不同層次的東西。
  • Spark Streaming 是「微批次」：把串流切成很小的批次處理；Flink 是逐事件處理的「原生串流」。題目問「真正即時、毫秒級」優先想 Flink。
  • 資料增強 vs SMOTE：資料增強泛指變形既有樣本（翻轉圖片、同義詞替換）；SMOTE 專指在表格資料中，於少數類樣本之間「內插」產生新樣本，用於類別不平衡。
📌 考試重點Label Encoding 用於有序類別、誤用於無序類別會產生虛假順序；One-hot 用於無序類別、高基數會維度爆炸；Target Encoding 需防資料洩漏；Min-Max 與 Z-score 對極端值敏感，Robust Scaling 以中位數與 IQR 抗極端值；特徵選擇 Filter／Wrapper／Embedded；特徵衍生目的是建立更具意義、可解釋的變數；即時監控交易異常用串流處理系統（Flink、Kafka）；Spark 為記憶體運算、Hadoop 為批次；管線設計原則：可重現、容錯、擴充、可觀測。

📖 名詞小辭典

型別轉換Type Casting
把資料轉成正確型態，如字串轉日期、整數轉浮點數。例：「2025-03-01」字串轉成可做日期加減的 datetime。
ISO 8601ISO 8601 Date/Time Format
國際標準的日期時間寫法 YYYY-MM-DDThh:mm:ss。例：2026-10-12T09:30:00+08:00。
分箱（離散化）Binning（等寬、等頻、K-Means 分箱）
把連續數值切成區間；等寬每段寬度相同、等頻每段筆數相同、K-Means 依資料聚集處切。例：消費金額分成低、中、高三級。
高基數High Cardinality
一個類別欄位有非常多不同值。例：商品編號、郵遞區號。
標籤編碼Label Encoding
每個類別給一個整數編號。例：S=1、M=2、L=3。
獨熱編碼One-hot Encoding
每個類別一欄，是就填 1、否則 0。例：付款方式拆成「現金、信用卡、行動支付」三欄。
目標編碼Target Encoding
用該類別在目標變數上的統計值（如平均轉換率）代替類別。例：各縣市以其歷史違約率表示。
特徵縮放Feature Scaling
讓各特徵數值範圍相近，對 KNN、梯度下降、正則化模型很重要。例：年收入與年齡縮到相近範圍。
Min-Max 正規化Min-Max Normalization
(x − 最小值)/(最大值 − 最小值)，縮到 0～1。例：圖片像素 0～255 除以 255。
Z-score 標準化Z-score Standardization
(x − 平均)/標準差，轉成平均 0、標準差 1。例：PCA 前先標準化，避免大單位欄位主導。
穩健縮放Robust Scaling
(x − 中位數)/IQR，不受極端值影響。例：含少數巨額交易的金額欄。
特徵工程Feature Engineering
從原始資料設計出對模型更有用的輸入變數。例：由交易紀錄算出「最近一次購買距今天數」。
資料洩漏Data Leakage
訓練時不小心用到預測當下不該知道的資訊，使評估虛高。例：用全資料算標準化參數再切訓練／測試集。
特徵選擇Feature Selection（Filter／Wrapper／Embedded）
挑出有用特徵、剔除雜訊特徵的方法：過濾法、包裝法、嵌入法。例：200 個欄位挑出 30 個最有用的。
遞迴特徵消除Recursive Feature Elimination, RFE
反覆訓練模型、每次刪掉最不重要的特徵（包裝法的一種）。例：逐輪刪到剩 10 個特徵。
Lasso／Ridge 正則化L1 (Lasso) / L2 (Ridge) Regularization
在模型損失中加入「係數大小懲罰」；Lasso 會把不重要的係數壓到 0（自動選特徵），Ridge 只會縮小。例：Lasso 迴歸自動淘汰無用欄位。
交互特徵／時間特徵／聚合特徵Interaction / Temporal / Aggregate Features
兩特徵相乘組合／由時間衍生（星期、假日、Recency）／統計匯總（近 3 個月平均）。例：消費頻率 × 平均金額。
RecencyRecency
距離最近一次行為（如購買）的時間，RFM 顧客分析的 R。例：90 天沒買的會員流失風險高。
資料增強Data Augmentation
透過變形既有資料產生更多訓練樣本。例：把瑕疵照片翻轉、旋轉、調亮度。
抖動／縮放（時序增強）Jittering / Scaling
對時間序列加小雜訊或整體放大縮小，以產生新樣本。例：感測器訊號加入微小隨機擾動。
SMOTESynthetic Minority Over-sampling Technique
在少數類樣本與其鄰居之間內插，合成新的少數類樣本。例：詐欺樣本只有 0.1%，用 SMOTE 補足。
MapReduceMapReduce
先「分頭處理（Map）」再「彙總結果（Reduce）」的分散式批次運算模型。例：統計 10 TB 日誌中每個網址被訪問次數。
Apache Spark／MLlibApache Spark / MLlib
以記憶體運算為主的分散式引擎，MLlib 是其機器學習函式庫。例：用 Spark 訓練上億筆資料的推薦模型。
Apache FlinkApache Flink
原生串流處理引擎，逐事件處理並維護狀態。例：即時偵測同一張卡 1 分鐘內在兩國刷卡。
Apache BeamApache Beam
統一批次與串流的程式模型，可在 Flink、Spark、Google Dataflow 上執行。例：同一份程式在地端與雲端都能跑。
批次／串流／微批次Batch / Stream / Micro-batch Processing
累積一批再處理／資料一到就處理／切成很小的批次近即時處理。例：月報表／即時告警／每 2 秒更新一次的儀表板。
資料管線Data Pipeline
把資料從來源經過一連串處理送到目的地的自動化流程。例：POS → 清理 → 倉儲 → 報表，每天自動跑。
可觀測性Observability
透過日誌、指標、追蹤了解系統內部狀態的能力。例：一眼看出哪個管線步驟卡住。
Luigi／Prefect／Kubeflow PipelinesWorkflow Orchestrators
工作流程編排工具：Luigi 輕量（Spotify 開源）、Prefect 重視容錯與監控、Kubeflow Pipelines 專注 Kubernetes 上的 ML 流程。例：每週自動重訓模型的流程。
DAGDirected Acyclic Graph（有向無環圖）
用箭頭表示任務先後、且不會繞回原點的流程圖，Airflow 以此定義工作流程。例：「下載 → 清理 → 匯入 → 寄報表」。
CI/CDContinuous Integration / Continuous Delivery（Deployment）
程式變更後自動測試、整合並部署的流程（GitHub Actions、Jenkins）。例：改了清理規則，自動跑測試後上線。
容器化／KubernetesContainerization (Docker) / Kubernetes (K8s)
把程式與環境打包成容器；Kubernetes 負責大量容器的部署、擴縮與修復。例：流量大時自動多開幾個模型服務容器。
Grafana／PrometheusMonitoring Tools
Prometheus 蒐集監控指標，Grafana 把指標畫成儀表板並設定告警。例：管線失敗率超過 5% 時通知 Slack。
🚀 延伸與新進展考試範圍外
  • ETL → ELT 與 dbt（2016 起；2025 年 Fivetran 與 dbt Labs 宣布合併）：雲端倉儲運算變便宜後，流行「先載入原始資料（EL），再在倉儲裡用 SQL 轉換（T）」。dbt 讓分析師用 SQL＋版本控制＋自動測試管理轉換邏輯；2025 年 10 月資料搬運工具 Fivetran 與 dbt Labs 宣布合併，顯示「搬運＋轉換」走向整合。和指引的 ETL 差在：轉換延後、在倉儲內完成、原始資料保留可重算。
  • 單機分析引擎崛起（2024，DuckDB 1.0、Polars 1.0）：DuckDB（2024 年 6 月 1.0）是「嵌入式的分析型 SQL 資料庫」，Polars（2024 年 7 月 1.0）是以 Rust 打造的高速 DataFrame 函式庫。一台筆電就能處理過去需要小型 Spark 叢集的數十 GB 資料——提醒我們不是所有「大」資料都需要分散式架構。
  • Spark 4.0（2025）：2025 年 5 月發布，預設啟用 ANSI SQL 模式（溢位、除以零會明確報錯而非默默變成 null）、新增 VARIANT 型別處理半結構化資料、強化 Spark Connect 輕量用戶端與 SQL 管線語法。
  • Flink 2.0（2025）：2025 年 3 月發布，是 Flink 1.0 以來首個大版本，核心是「存算分離」的狀態管理：狀態主要存放在遠端分散式檔案系統，本地磁碟當快取，讓擴縮與故障恢復更快、更適合雲端。
  • Airflow 3.0（2025）：2025 年 4 月發布，改為服務導向架構，任務可在遠端環境執行，並支援 DAG 版本管理與事件驅動排程。

5.1 統計學在大數據中的應用 完整教材 ↗

💬 白話說很多人以為「資料夠多，偏誤就會消失」——錯！如果你只在百貨公司門口做問卷，問一萬人跟問一百萬人，結論一樣偏向「有錢逛百貨的人」，而且因為樣本超大、信賴區間超窄，錯得更有自信。這就是指引說的「結構性偏誤被放大並看似穩定」。

p 值膨脹：樣本大到什麼都「顯著」

算例：A、B 兩版網頁各 100 萬名使用者，平均停留時間只差 0.01 個標準差（Cohen's d = 0.01，幾乎無感）。
檢定統計量 z ≈ 0.01 ÷ √(2/1,000,000) ≈ 7.07 → p 值遠小於 0.0001，「極度顯著」！
但這個差異對營收可能毫無意義 → 要看效果量、信賴區間與實務意義，不能只看 p。

多重檢定：試越多次，越容易「中獎」

在 α = 0.05 下做 20 個彼此獨立、其實都沒效果的檢定：
至少一個「假顯著」的機率 = 1 − 0.95²⁰ ≈ 0.64（64%！）；做 1,000 次則預期約 50 個假顯著（與指引一致）。

兩種校正方式，用一個小例子比較（5 個檢定的 p 值排序後：0.001、0.012、0.014、0.041、0.20，目標水準 0.05）：

方法控制什麼門檻結果
BonferroniFWER：「至少錯一個」的機率（很嚴格）每個都用 0.05/5 = 0.01只有 0.001 顯著（1 個）
Benjamini-Hochberg（FDR）FDR：「宣稱顯著的結果中，假的比例」（較寬容）第 i 小的 p 值與 0.05 × i/5 比較：0.01、0.02、0.03、0.04、0.050.001≤0.01、0.012≤0.02、0.014≤0.03 成立，第 4 個 0.041>0.04 不成立 → 前 3 個顯著
🧠 記憶口訣樣本偏、p 膨脹、檢太多、不獨立、母體糊、算不動
大數據統計推論六大限制：樣本非隨機、p 值膨脹、多重檢定、樣本非獨立、母體定義不清、系統資源限制。解方關鍵字：效果量、信賴區間、Bonferroni／FDR、抽樣加權。
⚠️ 易混淆
  • Bonferroni vs FDR：Bonferroni 怕「錯任何一個」，適合確認性、代價高的決策（藥物）；FDR 容忍少量假陽性，適合大量探索（上千個基因、上百個行銷指標）。
  • 樣本非獨立：同一位使用者貢獻 500 筆點擊，不等於 500 個獨立樣本；把它們當獨立會讓信賴區間過窄、誤判顯著。
  • 統計顯著 ≠ 實務顯著：有差（p 小）跟差得有意義（效果量大）是兩件事。
📌 考試重點大數據推論六大陷阱（見上口訣）；樣本極大時 p 值膨脹，應搭配效果量（effect size，如 Cohen's d）、信賴區間與實務意義；多重檢定以 Bonferroni 或 FDR（Benjamini-Hochberg）控制；樣本非獨立使信賴區間過窄；Bootstrap、Permutation Test、Bayesian Estimation 在大數據上運算成本高；平均數在長尾資料失真，需搭配中位數與分位數。

📖 名詞小辭典

結構性偏誤Structural Bias
資料蒐集方式本身就系統性地漏掉或偏重某些群體。例：App 行為資料天生沒有「不用智慧型手機的長者」。
選樣偏誤Selection Bias
樣本不是隨機選出、與母體不同而導致的偏誤。例：只分析留下評論的顧客（通常特別滿意或特別生氣）。
p 值膨脹p-value Inflation
樣本數極大時，微小差異也產生極小的 p 值。例：百萬樣本下 0.1 秒的差異也「顯著」。
效果量Effect Size（如 Cohen's d）
衡量差異「有多大」而非「是否存在」；Cohen's d = 兩組平均差 ÷ 合併標準差。例：d = 0.8 屬大效果。
多重檢定（多重比較）Multiple Testing / Multiple Comparisons
同時做很多次檢定，假陽性機會隨次數累積。例：一次比較 50 個商品類別的轉換率。
偽陽性False Positive
其實沒有效果卻判為有（型一錯誤）。例：健康的人被篩檢成陽性。
FWERFamily-Wise Error Rate（族系錯誤率）
一整組檢定中「至少出現一次型一錯誤」的機率；Bonferroni 控制它。例：20 次檢定都不校正，FWER 約 64%。
偽發現率False Discovery Rate, FDR（Benjamini-Hochberg 法）
在所有被宣告顯著的結果中，假的所占的預期比例；BH 法以排序後的 p 值逐一比較門檻來控制。例：控制 FDR = 5%，100 個發現中預期約 5 個是假的。
Bootstrap（自助法）Bootstrap
從樣本中有放回地重抽很多次，以重抽結果的分佈估計不確定性。例：估計中位數的 95% 信賴區間。
置換檢定Permutation Test
把組別標籤隨機打亂很多次，看真實差異在「打亂後的差異」中有多極端。例：不假設常態也能檢定 A/B 差異。
貝氏估計Bayesian Estimation
結合事前信念（先驗）與資料，得到參數的事後機率分佈。例：「轉換率落在 3%～4% 的機率是 90%」。
母體定義不清Ill-defined Population
不清楚資料代表的是哪一群人，導致錯誤外推。例：把某平台使用者的意見當成「全台民意」。
長尾分佈Long-tail Distribution
大部分值集中在少數區域，但有一條很長的稀疏尾巴。例：電商少數爆款＋大量冷門商品。
分位數Quantile / Percentile
把資料按比例切分的位置值；第 99 百分位數表示 99% 的值比它小。例：網站回應時間 P99 = 1.2 秒。
邏輯迴歸Logistic Regression
預測二元結果機率的迴歸模型。例：預測顧客會不會購買、貸款會不會違約。
K-means 分群K-means Clustering
把資料分成 K 群，使每群內的點離群中心最近。例：把會員分成高價值、潛力、沉睡三群。
ARIMA／SARIMAAutoRegressive Integrated Moving Average / Seasonal ARIMA
以「過去值＋差分＋過去誤差」建模的時間序列預測方法；SARIMA 加入季節性。例：預測下季用電量。
蒙地卡羅模擬Monte Carlo Simulation
用大量隨機模擬估計結果的分佈。例：模擬一萬種市場情境估計投資組合最大損失。
生存分析Survival Analysis（Kaplan-Meier、Cox 迴歸）
分析「到某事件發生要多久」，可處理尚未發生事件的資料；Kaplan-Meier 畫存活曲線，Cox 迴歸找影響因素。例：訂閱用戶多久後退訂。
統計製程管制Statistical Process Control, SPC（X-bar 控制圖）
用控制圖監測製程平均與變異是否超出管制界限。例：每小時抽 5 個零件量尺寸畫 X-bar 圖。
MADMedian Absolute Deviation（中位數絕對離差）
各值與中位數距離的中位數，抗極端值的離散指標，可用來偵測異常。例：取代標準差判斷感測器讀值是否異常。
核密度估計Kernel Density Estimation, KDE
在每個資料點放一個小山丘再加總，得到平滑的分佈曲線。例：估計正常流量分佈以識別 DDoS。
DDoSDistributed Denial of Service（分散式阻斷服務攻擊）
大量來源同時灌流量使服務癱瘓。例：購票網站開賣時被惡意流量打掛。
滑動視窗Sliding Window
只看最近一段時間（如 5 分鐘）的資料並隨時間往前滑動。例：最近 5 分鐘登入失敗超過 10 次就告警。
抽樣加權Sampling Weights
給代表性不足的群體較高權重，修正非隨機樣本的偏誤。例：網路問卷中長者回覆少，給予較高權重。
空間自迴歸Spatial Autoregression
考慮「鄰近地區彼此影響」的迴歸模型。例：某區房價受相鄰行政區房價影響。
🚀 延伸與新進展考試範圍外
  • 「大資料悖論」（2018，Meng）：統計學者孟曉犁在《Annals of Applied Statistics》論文中量化說明：有偏誤的超大樣本，可靠度可能不如一個小小的隨機樣本——呼應指引「偏誤被放大」的警告。
  • 因果推論工具普及（2018 起）：觀察型大數據無法隨機分組時，業界以差異中之差異、合成控制法、雙重機器學習（Double ML，2018）、DoWhy 套件等估計因果效果，回答「是行銷活動造成業績上升，還是剛好遇到連假？」
  • 保形預測（2005 年提出，近年廣用）：不論模型是什麼，都能給出「保證涵蓋率」的預測區間（例如 90% 的機會真值落在區間內），是信賴區間概念在機器學習時代的延伸。

💬 白話說：中心性在一個班級的 LINE 社群裡：Degree＝好友最多的人（人緣王）；Betweenness＝連接兩個小圈圈的「橋樑」，他不轉傳，兩群就不知道彼此的消息；Closeness＝離所有人都很近、傳話最快的人；PageRank＝「被重要的人認識」才算重要（Google 早期排序網頁的方法）。
💬 白話說：TF-IDF一個詞在這篇出現很多次（TF 高）、但在其他文章很少出現（IDF 高），就是這篇的關鍵詞。「的、是、了」每篇都有，IDF 趨近 0，自然被壓低。
IDF 算例（中級科目一勘誤後寫法）：1,000 篇文件中有 10 篇含「AI」→ IDF = log(1000/10) = log(100) = 2（以 10 為底）
💬 白話說：關聯規則（購物籃分析）1,000 張發票中，200 張有麵包（P(A) = 0.2）、100 張有牛奶（P(B) = 0.1）、50 張兩者都有（P(A∩B) = 0.05）。
支持度 = 0.05（這組合多常見）；信賴度 P(牛奶|麵包) = 0.05/0.2 = 0.25（買麵包的人 25% 也買牛奶）；提升度 = 0.05/(0.2×0.1) = 2.5 > 1，代表買麵包的人買牛奶的機率是一般人的 2.5 倍，正相關。

⚠️ 易混淆
  • Prophet 是 Meta（原 Facebook）開源的時序工具，擅長處理節慶效應與缺失值；不是深度學習模型。
  • Word2Vec vs BERT：Word2Vec 一個詞只有一個固定向量（「蘋果」水果與公司同一向量）；BERT 依上下文產生不同向量。
  • LOF vs Isolation Forest：LOF 看「我周圍的密度比鄰居稀疏多少」；Isolation Forest 看「我多快被隨機切出來」。
  • K-Means vs DBSCAN（地理群聚）：K-Means 要先指定群數、偏好圓形群；DBSCAN 依密度找任意形狀的群，並把稀疏點當雜訊。

Spark 上的分散式圖運算／Python 圖分析函式庫／圖形視覺化軟體。例：用 Gephi 畫出社群網絡圖。
RDF 三元組RDF Triple（Subject–Predicate–Object）
用「主詞—謂詞—受詞」表達一則知識，是知識圖譜的基本單位。例：（台積電, 總部位於, 新竹）。
斷詞Tokenization
把文字切成詞或子詞單位。例：「我愛台北」→「我／愛／台北」。
停用詞Stop Words
出現極頻繁但資訊量低的詞，分析前常移除。例：的、了、是、the、a。
詞形還原／詞幹提取Lemmatization / Stemming
還原成字典形並考慮詞性／直接截斷到詞幹、不考慮詞性。例：running → run（兩者皆可）；better → good（只有詞形還原做得到）。
TF-IDFTerm Frequency–Inverse Document Frequency
詞頻 × 逆文件頻率，突顯在本文常見但在全體少見的關鍵詞。例：從客訴中找出「退款」「延遲」等關鍵詞。
詞嵌入Word Embedding（Word2Vec、GloVe、FastText）
把詞變成向量，意思相近的詞向量也相近；GloVe 用共現矩陣、FastText 考慮子詞。例：「國王 − 男人 + 女人 ≈ 女王」。
BERT／RoBERTaBidirectional Encoder Representations from Transformers / Robustly optimized BERT
依上下文產生語意向量的 Transformer 語言模型。例：判斷「這手機真是『好』用到想摔」的反諷情緒。
情感分析Sentiment Analysis
判斷文字的正面、負面或中立情緒。例：監控品牌在社群上的聲量好壞。
命名實體辨識Named Entity Recognition, NER
從文字中找出人名、地名、組織、品牌等專有名詞。例：從新聞抽出提到的公司名稱。
LDA 主題模型Latent Dirichlet Allocation
自動從大量文件中找出潛在主題的非監督式方法。例：把十萬則評論歸納成「物流、價格、品質」等主題。
spaCy／Gensim／Spark NLP／Hugging Face TransformersNLP Libraries
常見的自然語言處理工具庫。例：用 Hugging Face 載入預訓練 BERT 做分類。
地理空間分析Geospatial Analysis
分析帶有位置資訊（點、線、面）的資料。例：外送平台規劃配送區。
空間自相關Spatial Autocorrelation
相近地點的數值往往相似（地理第一定律）。例：相鄰街區的房價相近。
空間異質性／地理加權迴歸Spatial Heterogeneity / Geographically Weighted Regression, GWR
同一因素在不同地方影響不同；GWR 為每個地點估計各自的迴歸係數。例：捷運站對房價的加成，在市中心與郊區不同。
Getis-Ord Gi*Getis-Ord Gi* Hot Spot Statistic
判斷某地及其鄰近區域是否形成統計上顯著的高值或低值聚集（熱點／冷點）。例：找出竊案熱點。
DBSCANDensity-Based Spatial Clustering of Applications with Noise
依密度分群，可找任意形狀的群並標記雜訊點。例：找出共享單車的熱門停放區。
空間插值Spatial Interpolation
用已知測站的值推估沒有測站地點的值。例：由空品測站推估全市 PM2.5 地圖。
GeoPandas／PostGIS／Apache Sedona／ArcGIS／QGISGeospatial Tools
Python 地理資料處理／PostgreSQL 空間擴充／分散式空間運算／商用與開源 GIS 軟體。例：用 PostGIS 查「方圓 500 公尺內的門市」。
異常偵測Anomaly Detection
找出與正常模式明顯不同的資料點或事件。例：信用卡盜刷、機台異常震動。
局部離群因子Local Outlier Factor, LOF
比較某點與其鄰居的局部密度，密度明顯較低者為異常。例：在一群正常交易中找出孤立的可疑交易。
Random Cut ForestRandom Cut Forest（Amazon）
Amazon 提出、適合串流資料的樹狀異常偵測演算法。例：即時監控網站流量異常。
PyODPython Outlier Detection
整合數十種異常偵測演算法的 Python 函式庫。例：一次比較 LOF、Isolation Forest 的效果。
主成分分析Principal Component Analysis, PCA
把多個相關欄位壓縮成少數保留最多變異的新軸；使用前須先標準化。例：把 50 個問卷題壓成 5 個主成分。
奇異值分解Singular Value Decomposition, SVD
可分解任意長方形矩陣的方法，用於降維與潛在語意分析（LSA）。例：使用者 × 商品評分矩陣降維做推薦。
關聯規則／AprioriAssociation Rules / Apriori Algorithm
找出「買 A 的人也常買 B」的規則；Apriori 先找高頻項目組合再產生規則。例：啤酒與尿布的經典故事。
支持度／信賴度／提升度Support / Confidence / Lift
P(A∩B)／P(B|A)／P(A∩B) ÷ [P(A)P(B)]；提升度 = 1 表示獨立、> 1 正相關、< 1 負相關。例：見上方麵包牛奶算例。

  • 時間序列基礎模型（2024）：Google 的 TimesFM（2024 年發表、ICML 2024）與 Amazon 的 Chronos（2024）以大量時間序列預訓練，可對沒看過的新序列做「零樣本預測」。和指引的 ARIMA、Prophet 差在：不必為每條序列各自調參建模，像 LLM 一樣「先預訓練、再直接用」。

  • HyperLogLog 去重計數（2007）：與 Count-Min Sketch 同屬「速寫」家族，用幾 KB 記憶體估計上億筆資料的「不重複數」，BigQuery 的 APPROX_COUNT_DISTINCT 等近似函數即屬此類技術。

第六章 大數據在人工智慧之應用

💬 白話說在 AI 時代，資料不只是「被分析的對象」，而是模型的「教科書」。教科書太厚（Volume）要分冊讀、內容太雜（Variety）要整理、更新太快（Velocity）要邊讀邊學、有錯字（Veracity）要校對、廢話太多（Value 密度低）要畫重點。本章談怎麼用這本教科書訓練鑑別式與生成式 AI，以及怎麼不侵犯書裡那些人的隱私。

6.1 大數據與機器學習 完整教材 ↗

🧠 記憶口訣量大分批、樣多融合、流快增量、真偽溯源、價低精選
5V 各自的因應策略：Volume → Mini-Batch／分散式；Variety → 多模態對齊融合；Velocity → 串流＋增量學習；Veracity → Data Lineage／漂移偵測；Value → 特徵選擇、降維、主動學習。
💬 白話說：不平衡資料與 Accuracy 陷阱1 萬筆交易中只有 10 筆詐欺。一個「永遠說不是詐欺」的笨模型，準確率高達 99.9%，卻一筆詐欺都沒抓到（召回率 0）。所以不平衡資料要看 F1、Balanced Accuracy、PR-AUC、Recall，並用類別加權、SMOTE 等方法處理。
💬 白話說：數據漂移 vs 概念漂移數據漂移：考題的「題型分佈」變了，例如顧客從年輕人為主變成銀髮族為主（輸入 X 的分佈改變）。概念漂移：同樣的題目，「正確答案」的規則變了，例如詐騙集團換了手法，過去看起來正常的行為現在是詐騙（X 與 Y 的關係改變）。兩者都會讓模型悄悄變笨，所以上線後要持續監控並觸發重訓。
💬 白話說：分散式訓練資料並行：十位老師各改一疊考卷（各拿一份完整模型、處理不同資料），最後把評分標準的修正意見（梯度）彙總。模型並行：一本書太厚一個人背不動，拆成章節分給不同人負責（模型太大，切到不同 GPU）。混合精度：草稿用鉛筆（FP16，快又省空間），定稿用原子筆（FP32，關鍵處保持精確）。
⚠️ 易混淆
  • 資料並行 vs 模型並行：切資料 vs 切模型。超大模型（GPT、BERT 規模）才需要模型並行。
  • 增量學習 vs 災難性遺忘：持續用新資料更新模型時，可能把舊知識忘光，需搭配回放舊資料或正則化等策略。
  • 評估切分要防洩漏：SMOTE、特徵篩選、標準化須在切分後只用訓練集；時序資料要依時間切（前進式驗證），不可隨機打散；同一病患多筆資料要整組放在同一側。
📌 考試重點5V 對機器學習的衝擊與因應；不平衡資料不能只看 Accuracy，改用 F1、Balanced Accuracy、Macro AUC／PR-AUC；漂移偵測可用 KS 檢定、KL 散度；分散式訓練分資料並行、模型並行、混合並行；混合精度訓練（16-bit＋32-bit）加速並省記憶體；預訓練＋微調；MLOps 包含資料管線、訓練驗證、部署（Batch／Online／Streaming）與持續監控重訓；解決資料與運算資源不對稱用分散式訓練與硬體加速。

把不同模態的資料在時間或語意上對應起來／把多模態特徵合併成一個表示。例：影片畫面與字幕時間對齊後一起輸入模型。
卷積神經網路Convolutional Neural Network, CNN
擅長擷取影像局部特徵的神經網路（如 ResNet、VGG）。例：X 光片判讀、產線瑕疵檢測。
類別不平衡Class Imbalance
某一類樣本遠少於其他類。例：詐欺交易只占 0.1%。
類別加權／成本敏感學習Class Weight / Cost-sensitive Learning
讓模型把少數類判錯的代價加重。例：漏抓詐欺的懲罰設為誤報的 50 倍。
欠抽樣／過抽樣Undersampling / Oversampling
減少多數類樣本／增加少數類樣本，以平衡類別比例。例：隨機抽掉部分正常交易。
弱標註（弱監督）Weak Supervision / Weak Labeling
用規則、詞典或啟發式自動產生「不完美但大量」的標籤。例：含「爛透了」就先標負面。
主動學習Active Learning
讓模型挑出最沒把握的樣本優先交給人工標註，用最少標註換最大進步。例：只請醫師標註模型最猶豫的 500 張影像。
F1 分數F1-score
精確率與召回率的調和平均，兩者都要好才高。例：詐欺偵測常用的綜合指標。
精確率／召回率Precision / Recall
判為陽性中真正陽性的比例／所有真陽性中被抓到的比例。例：零容忍攔截要最大化召回率（可調低判斷門檻）。
平衡準確率Balanced Accuracy
各類別召回率的平均，不會被多數類灌水。例：兩類召回率 0.99 與 0.5，平衡準確率 0.745。
Macro AUC／PR-AUCMacro-averaged AUC / Precision-Recall AUC
各類別 AUC 的平均（每類等權）／精確率—召回率曲線下面積，不平衡資料下比 ROC-AUC 更敏感。例：罕見疾病篩檢以 PR-AUC 評估。
公平性指標Demographic Parity / Equalized Odds
人口均等：各群體被判為陽性的比例相近；機會均等化：各群體的真陽性率與偽陽性率相近。例：貸款核准率不應因性別而系統性不同。
串流處理Stream Processing（Kafka、Flink、Spark Streaming、Kinesis、Pub/Sub、Event Hub）
資料一進來就處理；Kinesis、Pub/Sub、Event Hubs 分別是 AWS、Google Cloud、Azure 的串流服務。例：即時交易風控。
增量學習（線上學習）Incremental / Online Learning（Perceptron、SGDClassifier、River）
新資料到來就小幅更新模型，不必整批重訓；River 是專門的 Python 線上學習套件。例：新聞推薦依當天點擊即時調整。
金絲雀發布／A/B 測試Canary Release / A/B Testing
先讓小部分流量使用新模型，確認沒問題再全面切換／隨機分流比較新舊模型。例：新推薦模型先給 5% 使用者。
結構映射Schema Mapping
把不同來源欄位對應到統一的欄位定義。例：「cust_no」「客戶編號」都對應到 customer_id。
LakeFSLakeFS
為資料湖提供類似 Git 的分支、提交與回溯的版本控制工具。例：在資料分支上測試清理規則，沒問題再合併。
數據漂移／概念漂移Data Drift / Concept Drift
輸入資料分佈改變／輸入與標籤之間的關係改變。例：疫情後消費習慣改變（數據漂移）；詐騙手法翻新（概念漂移）。
KS 檢定Kolmogorov–Smirnov Test
比較兩組資料的累積分佈是否相同，常用於偵測漂移。例：比較本月與訓練時的年齡分佈。
KL 散度Kullback–Leibler Divergence
衡量兩個機率分佈差異的指標（非對稱）。例：線上特徵分佈與訓練分佈差距越大，KL 越大。
Evidently／WhyLabsML Monitoring Tools
監控模型與資料品質、漂移的工具。例：每日自動產生漂移報告。
自動化 EDAAutomated EDA（Sweetviz、Pandas Profiling）
一鍵產生資料概況報表的工具。例：新資料進來先產出缺失率與分佈報告。
資料並行／模型並行／混合並行Data / Model / Hybrid Parallelism
切資料給多個模型副本／把一個大模型切到多台裝置／兩者並用。例：訓練大型語言模型多採混合並行。
梯度Gradient
損失函數對參數的變化方向與大小，告訴模型「往哪調、調多少」。例：像下山時看腳下最陡的方向。
GPU／TPUGraphics Processing Unit / Tensor Processing Unit
擅長大量平行矩陣運算的加速晶片；TPU 是 Google 為機器學習設計的晶片。例：深度學習訓練幾乎都用 GPU。
SageMaker／Vertex AIAmazon SageMaker / Google Vertex AI
AWS 與 Google Cloud 的全託管機器學習平台。例：在雲端一鍵開多台 GPU 訓練。
混合精度訓練Mixed Precision Training（FP16＋FP32）
多數計算用 16 位元浮點數加速、省記憶體，關鍵累加保留 32 位元以維持精度。例：訓練速度明顯提升、可放更大的批次。
梯度累積／梯度壓縮Gradient Accumulation / Gradient Compression（Top-k Sparsification、Quantization）
累積多個小批次的梯度再更新，模擬大批次／只傳最大的 k 個梯度或降低位元數，減少節點間通訊量。例：GPU 記憶體不足時用梯度累積。
提前停止／檢查點Early Stopping / Checkpointing
驗證表現不再進步就停止訓練以防過擬合／定期保存模型狀態，中斷時可接續。例：訓練到第 30 輪自動停。
TFRecord／tf.dataTFRecord / tf.data API
TensorFlow 的高效二進位資料格式與資料讀取管線 API。例：讓 GPU 不必等資料讀取。
預訓練／微調Pre-training / Fine-tuning
先在大量通用資料上學基本能力，再用少量任務資料調整。例：通用語言模型微調成客服問答模型。
災難性遺忘Catastrophic Forgetting
模型學新任務後，舊任務能力大幅下降。例：微調成法律模型後，一般常識變差。
MLOpsMachine Learning Operations
把機器學習模型的開發、部署、監控、重訓自動化與標準化的實務。例：偵測漂移後自動重訓並經 CI/CD 上線。
MLflow／Weights & BiasesExperiment Tracking Tools
記錄每次實驗的參數、資料版本、指標與模型的工具。例：比較 30 次調參結果。
批次／線上／串流推論Batch / Online (API) / Streaming Inference
定期整批預測／即時 API 回應單筆請求／對串流事件持續預測。例：每晚算流失分數／刷卡當下判斷盜刷。
藍綠部署Blue-Green Deployment
同時維持新舊兩套環境，一鍵切換流量，有問題可立即切回。例：新模型上線失敗，秒切回舊版。
🚀 延伸與新進展考試範圍外
  • FSDP／ZeRO 分片式資料並行（ZeRO 2019、PyTorch FSDP 2023 論文）：傳統資料並行每張 GPU 都存一份完整模型；分片式做法把參數、梯度、優化器狀態切開分給各 GPU，需要時才彙整，讓「資料並行」也能訓練超大模型，介於指引的資料並行與模型並行之間。
  • FP8 混合精度（2024，DeepSeek-V3 技術報告）：從 FP16 再往下到 8 位元浮點數，DeepSeek-V3 技術報告展示以 FP8 混合精度訓練大型模型，進一步降低記憶體與運算成本——是指引「FP32＋FP16」的延伸。
  • 參數高效微調（2021，LoRA）：只訓練插入的少量低秩矩陣，就能微調大型模型，大幅減少運算與儲存需求，是指引「預訓練＋微調」的主流做法。
  • 特徵商店（2017 Uber Michelangelo、2019 Feast 開源）：集中管理特徵的計算邏輯與歷史值，保證「訓練時」與「線上推論時」用的是同一份特徵定義，並可依時間點取值以避免資料洩漏。
  • 資料中心 AI（2021，吳恩達倡議）：與其一直換模型，不如系統化改善資料（標註一致性、涵蓋邊界案例、清理雜訊）。這與本節「5V」與資料品質的精神一致。

6.2 大數據在鑑別式 AI 的應用 完整教材 ↗

💬 白話說鑑別式 AI 是「裁判」：給它一筆資料，它判斷這是哪一類、會不會發生。它學的是不同類別之間的「分界線」（決策邊界）。企業最常用的 AI 大多屬於這類：信用評分、詐欺偵測、流失預測、垃圾郵件過濾、影像瑕疵檢測。它最大的挑戰往往不是模型，而是標註——誰來告訴模型哪些是詐欺？
標註策略比喻何時用
人工標註請專科醫師一張張判讀需要專業、準確度要求高
弱監督用「關鍵字規則」先粗分需要快速大量、可容忍雜訊
群眾外包請很多工讀生分工簡單任務、需大量，搭配一致性檢查
主動學習老師只回答學生最不懂的題目標註昂貴，想用最少標註換最大效益
🧠 記憶口訣人工準而貴、弱監快而粗、外包多而雜、主動挑難題
跨來源整合四難：主鍵不一致、時區不同、更新頻率不同、品質不均。
⚠️ 易混淆
  • 時區陷阱：系統 A 存 UTC、系統 B 存台北時間（UTC+8），直接合併會讓「晚上 11 點的交易」跑到隔天，影響日彙總與時間特徵。
  • 資料品質如何影響統計：缺失值 → 偏誤的均值與 t 檢定；異常值 → 放大誤差；重複值 → 高估權重；一致性錯誤 → 分組錯誤影響 ANOVA；邏輯錯誤 → 模型學到錯誤模式。
📌 考試重點鑑別式 AI 專注於資料分類與預測、學習決策邊界；常見應用：金融風險（信用評分、詐欺、AML）、零售推薦與流失、客服文本分類、醫療診斷、資安異常偵測；輸入可為結構化、半結構化（需解析／展平）、非結構化（需特徵萃取）、多模態（需融合）；四種標註策略的優缺點。

📖 名詞小辭典

鑑別式 AI（判別式 AI）Discriminative AI
學習輸入與標籤間的決策邊界，用於分類與預測。例：判斷郵件是否為垃圾信。
決策邊界Decision Boundary
模型在特徵空間中劃分不同類別的分界。例：收入與負債比形成的一條「核貸／不核貸」線。
信用評分Credit Scoring
預測借款人違約可能性並給予分數。例：申辦信用卡時的核卡評估。
反洗錢Anti-Money Laundering, AML
偵測與防範將非法所得偽裝成合法資金的行為。例：偵測多帳戶小額分散匯入再集中轉出。
隨機森林Random Forest
許多決策樹投票的集成模型，穩定且不易過擬合。例：顧客流失預測。
XGBoost／LightGBMGradient Boosting Libraries
以梯度提升法逐棵補強錯誤的樹模型，表格資料常勝軍。例：信用風險模型。
CLIPContrastive Language–Image Pre-training
同時學習圖片與文字對應關係的多模態模型（OpenAI，2021）。例：用文字描述搜尋商品圖片。
單純貝氏分類器Naive Bayes
假設特徵彼此獨立、用貝氏定理計算類別機率的簡單分類器。例：早期垃圾郵件過濾。
支援向量機Support Vector Machine, SVM
找出讓兩類間隔最大的分界線的分類模型。例：文本分類。
正規表示式Regular Expression, Regex
描述文字樣式的規則語法，用來比對與抽取。例：抓出所有手機號碼 09 開頭 10 碼。
臨床決策支援Clinical Decision Support
以資料與模型輔助醫師診斷與治療決策的系統。例：提示可能的藥物交互作用。
釣魚郵件Phishing Email
假冒可信單位誘騙點擊或輸入帳密的郵件。例：假冒銀行要求「重新驗證帳戶」。
解析／展平Parsing / Flattening
把 JSON、XML 等巢狀結構拆成表格欄位。例：訂單 JSON 的多個商品展開成多列。
點擊流Clickstream
使用者在網站或 App 上依序的點擊與瀏覽紀錄。例：首頁 → 搜尋 → 商品頁 → 放入購物車。
特徵萃取Feature Extraction
把非結構化資料轉成數值向量。例：用 CNN 把照片轉成 512 維向量。
特徵級融合Feature-level Fusion
把不同模態的特徵向量串接後一起輸入模型。例：用戶屬性＋評論向量＋圖片向量合併。
群眾外包Crowdsourcing（Amazon MTurk、Appen）
把標註任務拆小分給大量線上工作者。例：請數千人標註圖片中是否有貓。
標註一致性Inter-annotator Agreement
不同標註者對同一筆資料給出相同標籤的程度。例：三人中有兩人以上同意才採用。
主鍵Primary Key
唯一識別每一筆資料的欄位。例：會員編號。
UTCCoordinated Universal Time（世界協調時間）
國際標準時間；台灣時間為 UTC+8。例：UTC 16:00 = 台北 24:00。
🚀 延伸與新進展考試範圍外
  • 以 LLM 輔助標註（2023 起）：用大型語言模型先產生初步標籤，再由人工抽查修正，是「弱監督＋主動學習」的新版本；但模型可能帶有自身偏誤，需量測與人工標註的一致性。
  • 程式化弱監督（2017，Snorkel）：把多條規則寫成「標註函數」，再用統計模型估計各規則的可信度並合併成機率標籤，比單一規則更準。
  • 表格基礎模型（2025，TabPFN）：2025 年 1 月發表於《Nature》的 TabPFN，在數百萬個合成表格資料集上預訓練，可對小型表格資料直接預測，為「表格資料只能用樹模型」帶來新選項；目前仍以中小型資料集為主。

6.3 大數據在生成式 AI 的應用 完整教材 ↗

💬 白話說生成式 AI 像一位讀遍天下書的作家，它寫出的東西反映它讀過什麼：只讀過某類書（多樣性不足）就只會一種文風；讀的書都是同一群人寫的（代表性不足）就會有刻板印象，例如提到醫師就預設是男性；讀到錯誤百出的書（品質差）就會胡說；書都很舊（時效性差）就不知道新流行語。所以「餵什麼」決定「生出什麼」。
🧠 記憶口訣多樣、代表、品質、時效
生成式 AI 資料選擇四面向；偏誤類型記「性別族群、地區文化、社經地位、來源平台」。
⚠️ 易混淆
  • 鑑別式 vs 生成式的資料需求：鑑別式重視「標註好、格式一致」；生成式重視「開放、語意豐富、語境完整」的大量語料。
  • 合成資料不是越多越好：用模型生成的資料反覆訓練下一代模型，可能逐漸忘掉真實資料中的罕見情況（見下方「模型崩潰」）。
📌 考試重點生成式 AI 核心為「學習表徵後產生新內容」，資料需求開放、語意驅動；品質關鍵在訓練樣本的多樣性與語境一致性；四面向：多樣性、代表性與偏誤、品質正確性、時效性；應用：語言生成、圖像生成、多模態生成、合成資料增強；結構化輸入要產出自然語言用語言生成模型。

📖 名詞小辭典

生成式 AIGenerative AI
學習資料的分佈與表徵後，產生新的文字、影像、聲音等內容。例：輸入商品規格自動寫出行銷文案。
表徵（表示）Representation
模型內部用來描述資料特性的數值形式。例：把一句話轉成 768 維向量。
大型語言模型Large Language Model, LLM
以海量文字訓練、能理解與生成語言的大型 Transformer 模型。例：智慧客服、文件摘要。
語料Corpus
用於訓練或分析的大量文字集合。例：新聞、百科、論壇文章的集合。
資料多樣性Data Diversity
資料涵蓋的主題、風格、語言、情境、模態是否夠廣。例：客服資料同時含正式與口語提問。
資料代表性Data Representativeness
資料是否公平反映實際使用者群體。例：語音模型的訓練資料是否包含各地口音。
系統性偏見Systematic Bias
因資料不平衡而在輸出中持續出現的偏差或刻板印象。例：生成「工程師」圖片幾乎都是男性。
資料時效性Data Freshness / Timeliness
資料是否反映當前環境與新知。例：模型不知道最新法規修正。
智慧客服／虛擬助理Chatbot / Virtual Assistant
以對話方式回答問題或代辦事務的系統。例：銀行 App 的線上客服。
程式碼生成Code Generation
由自然語言描述或上下文自動產生、補全程式碼。例：輸入「讀取 CSV 並畫長條圖」自動寫出 Python。
風格轉換Style Transfer
保留內容但改變圖片或文字風格。例：把產品照轉成水彩風。
文字生成圖像Text-to-Image（如 DALL·E）
依文字描述產生圖片。例：「夕陽下的台北 101，插畫風」。
擴散模型Diffusion Model
學習把雜訊一步步還原成圖像的生成模型，是主流影像生成技術。例：多數文字生圖工具採用此類模型。
生成對抗網路Generative Adversarial Network, GAN
生成器與判別器互相對抗學習的生成模型。例：生成擬真人臉。
合成資料Synthetic Data
以演算法或生成模型產生、模仿真實統計特性的資料。例：模擬罕見的感測器故障訊號來訓練模型。
魯棒性（穩健性）Robustness
模型面對雜訊、變化或刻意干擾時維持表現的能力。例：照片稍微模糊仍能正確辨識。
🚀 延伸與新進展考試範圍外
  • 檢索增強生成（RAG）與向量檢索（2020 提出，2023 起普及）：解決指引所說的「時效性」問題的主流做法——不必重訓模型，而是把企業最新文件切段、轉成嵌入向量存進向量資料庫，提問時先檢索相關段落再交給 LLM 回答，並可附出處。資料工程（清理、切段、權限）直接決定 RAG 品質。
  • GraphRAG（2024）：Microsoft Research 提出，以 LLM 從文件建出實體關係圖，再做社群偵測與分層摘要，擅長回答需要綜觀整批資料的問題（見 5.2）。
  • 預訓練資料的大規模清理（2024，FineWeb）：Hugging Face 公開 FineWeb 資料集論文（NeurIPS 2024），從 96 次 Common Crawl 網頁快照中去重、過濾出約 15 兆 token，並以模型挑出「教育性」子集 FineWeb-Edu，顯示資料篩選品質會明顯影響模型能力——本節「資料品質」的大規模實證。
  • 合成資料訓練語言模型（2023，Phi-1）：Microsoft 的〈Textbooks Are All You Need〉以高品質的「教科書式」合成資料訓練小型程式碼模型，展示資料品質可部分取代規模。
  • 模型崩潰（2024，Nature）：Shumailov 等人在《Nature》發表研究，指出模型若反覆以前一代模型生成的資料訓練，會逐漸遺失原始分佈的尾端（罕見內容），最終品質崩壞。實務啟示：合成資料要與真實資料混合並標記來源，不能完全取代真實資料。

6.4 大數據隱私保護、安全與合規 完整教材 ↗

💬 白話說把姓名刪掉不等於匿名。「30 歲、女性、住在某郵遞區號、每週三晚上去同一間健身房」——這幾個看似無害的準識別資訊一組合，就可能只剩你一個人。所以隱私保護分兩層：基礎匿名化（遮蔽、雜湊、泛化、分桶、加噪音）處理單一欄位；進階隱私強化技術（K-匿名、差分隱私、聯邦學習、同態加密）從整體資料集或運算方式下手。

K-匿名小算例

年齡（泛化後）郵遞區號（泛化後）疾病（敏感欄位）
30–39106**感冒
30–39106**糖尿病
30–39106**胃炎

這三筆在準識別欄位（年齡、郵遞區號）完全相同 → 達到 3-匿名：攻擊者最多只能鎖定到「3 人中的某一位」。若三人疾病都是「糖尿病」，雖然 3-匿名，敏感資訊仍外洩——這就是 L-多樣性要求「敏感欄位至少 L 種值」的原因；T-接近性再進一步要求該群組的疾病分佈接近整體分佈。

💬 白話說：四種進階技術
  • 差分隱私：在統計結果中加入精心設計的雜訊，使「有沒有你這筆資料」幾乎不影響結果——你就能合理否認自己在資料裡。隱私預算 ε 越小，保護越強、精度越低。
  • 聯邦學習：「模型去找資料，而不是資料來找模型」。各家醫院在本地訓練，只把模型更新（梯度）傳回中央彙整，病歷不出院。
  • 同態加密：把資料鎖在透明的保險箱裡，雲端可以隔著箱子做運算，但永遠看不到內容；結果拿回來用自己的鑰匙解開，與用明文算的一樣。代價是運算非常慢。
  • K-匿名系列：讓每個人「混在人群中」，至少有 K−1 個長得一樣的同伴。
🧠 記憶口訣差分加噪、聯邦不搬、同態密算、K 匿混群
合規五原則：「合法透明、目的限制、資料最小、期限刪除、可追可刪」。
⚠️ 易混淆
  • 雜湊 ≠ 絕對安全：身分證號、手機號碼這類「可能值有限」的短 ID，攻擊者可把所有可能值都算一次雜湊做成對照表（彩虹表）反查；實務常加入秘密鹽值（salt）或使用金鑰雜湊。
  • 去識別化 vs 匿名化：去識別化後若仍可透過額外資訊重新識別，在多數法規下仍屬個人資料；真正無法再識別的匿名資料才能脫離個資法規範，因此指引強調須定期做重識別風險測試。
  • 聯邦學習不是「絕對不外洩」：傳送的梯度仍可能被逆向推導，常需搭配差分隱私或安全聚合。
  • 成員推斷攻擊：攻擊者觀察模型對某筆資料是否「特別有信心」，推斷它是否在訓練集中；可用差分隱私、降低輸出信心值等方式防禦。
📌 考試重點識別資訊分直接識別、準識別、敏感資料；風險來源為橫向比對、時間軸拼接、保護不足；基礎匿名化：遮蔽、雜湊（SHA-256，短 ID 易受彩虹表）、泛化、分桶、隨機擾動；進階 PETs：K-匿名／L-多樣性／T-接近性、差分隱私（加嚴格控制的雜訊、數學保證、DPSGD）、聯邦學習（只傳參數）、同態加密（密文運算）；避免使用敏感欄位用資料匿名化；強化隱私用差分隱私；醫療資料須合法授權與同意；確保可追溯用資料版本管理與操作紀錄；持續合規需 AI 治理框架與跨部門監管；合規原則：合法透明、目的限制、資料最小化、保存期限、可刪除（被遺忘權）。
⚠️ 指引寫法（作答依此）vs. 法規現況指引以 GDPR、CCPA 與台灣個資法說明合規原則，作答依指引。法規面近年有更新（見下方延伸區），例如台灣個資法已於 2025 年再次修正、主管機關將轉為個人資料保護委員會；實務引用條文前請查全國法規資料庫最新版本。

📖 名詞小辭典

再識別Re-identification
把看似匿名的資料重新連結回特定個人。例：結合公開的選民名冊與「匿名」病歷找出某人。
個人可識別資訊Personally Identifiable Information, PII
能直接或間接識別個人的資訊。例：姓名、身分證號、電話、Email。
直接識別資訊Direct Identifier
單獨就能指向特定個人的資訊。例：身分證字號、裝置 ID。
準識別資訊Quasi-identifier
單獨無法識別、但組合後可指向個人的資訊。例：性別＋出生年月＋郵遞區號。
敏感資料Sensitive Data
一旦外洩會造成重大傷害的資料。例：病歷、信用狀況、宗教信仰。
橫向比對／時間軸拼接Linkage Attack / Trajectory Linking
結合外部資料比對出身分／從行為軌跡的時間序列推斷身分。例：從每天上下班的 GPS 軌跡推出住址與公司。
個人資料保護法Personal Data Protection Act, PDPA（台灣個資法）
台灣規範個資蒐集、處理、利用的法律。例：蒐集前須告知目的與當事人權利。
遮蔽Masking
以符號替換部分內容。例：王○明、0912-***-678。
雜湊Hashing（SHA-256）
把資料轉成固定長度、不可逆的字串，同樣輸入得到同樣輸出，可用於比對。例：兩家公司比對共同客戶而不交換原始 Email。
彩虹表攻擊Rainbow Table Attack
預先計算大量可能值的雜湊對照表來反查原值。例：反查手機號碼的雜湊值。
泛化Generalization
降低資料精細度。例：1987-03-12 → 1980 年代。
資料分桶Bucketing
把連續數值轉成區間。例：年收入 → 50 萬～60 萬。
隨機擾動（加噪）Noise Injection / Perturbation
加入小幅隨機數，保留整體統計但模糊個別值。例：薪資 50,000 → 50,123。
隱私強化技術Privacy-Enhancing Technologies, PETs
在利用資料的同時降低隱私風險的技術總稱。例：差分隱私、聯邦學習、同態加密。
K-匿名／L-多樣性／T-接近性k-Anonymity / l-Diversity / t-Closeness
準識別欄位至少 K 筆相同／敏感欄位至少 L 種值／群組內敏感值分佈與整體相近。例：見上方 3-匿名算例。
差分隱私Differential Privacy, DP
在查詢或訓練中加入受控雜訊（拉普拉斯或高斯），使單筆資料存在與否對結果影響極小，具數學保證。例：公布統計數據時保護個別受訪者。
隱私預算Privacy Budget, ε (epsilon)
差分隱私中控制保護強度的參數；ε 越小越隱私、但越不準，多次查詢會累積消耗。例：設定全年查詢總預算 ε = 1。
拉普拉斯／高斯機制Laplace / Gaussian Mechanism
差分隱私中加入符合拉普拉斯或高斯分佈雜訊的方法。例：統計人數加上拉普拉斯雜訊。
DP-SGDDifferentially Private Stochastic Gradient Descent
訓練時裁切每筆資料的梯度並加雜訊，使模型具差分隱私。例：訓練不會記住個別病歷的醫療模型。
聯邦學習Federated Learning
資料留在各端，本地訓練後只上傳模型更新給中央彙整。例：手機輸入法在裝置上學習用字習慣。
同態加密Homomorphic Encryption, HE（FHE 全同態加密）
可直接在密文上運算、解密後結果與明文運算相同的加密技術；FHE 支援任意運算但非常耗資源。例：雲端不解密就能幫你算加總。
成員推斷攻擊Membership Inference Attack
判斷某筆資料是否曾被用來訓練模型的攻擊。例：推斷某人病歷是否在某醫院模型的訓練集中。
目的限制原則Purpose Limitation
資料只能用於當初告知的目的。例：為出貨蒐集的地址不能拿去賣給廣告商。
資料最小化原則Data Minimisation
只蒐集達成目的所需的最少資料。例：寄電子報只需 Email，不必要身分證號。
保存期限限制Storage Limitation
超過必要期間就刪除或匿名化。例：求職者資料在招募結束後半年刪除。
被遺忘權Right to be Forgotten / Right to Erasure
當事人可要求刪除其個資的權利。例：退會時要求刪除所有消費紀錄。
明確同意Explicit Consent
當事人在充分告知下，主動、清楚表示同意。例：勾選「同意將病歷用於 AI 研究」。
IRBInstitutional Review Board（人體研究倫理審查委員會）
審查涉及人體或個資之研究是否合乎倫理與法規的委員會。例：醫院 AI 研究使用病歷前須經 IRB 核准。
去識別化De-identification
移除或處理識別資訊，降低識別個人的可能。例：病歷移除姓名與身分證號並泛化日期。
跨境傳輸Cross-border Data Transfer
把個資傳到其他國家處理或儲存，常受法規限制。例：把台灣客戶資料存到海外雲端機房。
資料治理委員會Data Governance Committee
由法務、資安、資料科學、業務組成，制定與監督資料使用政策的組織。例：審核新 AI 專案能否使用客戶資料。
AI 長／資料管家Chief AI Officer / Data Steward
負責企業 AI 策略與治理的高階主管／負責特定資料集品質、定義與存取的負責人。例：Data Steward 決定「營收」欄位的正式定義。
模型卡Model Card
記錄模型用途、訓練資料、效能、限制與公平性評估的說明文件。例：註明「不適用於 18 歲以下族群」。
敏感資料偵測Sensitive Data Discovery
自動掃描資料庫與檔案，找出含個資或敏感資訊的位置。例：發現某共享資料夾內有未遮蔽的身分證號。
