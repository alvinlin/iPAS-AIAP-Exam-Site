範例 1

貝氏定理：陽性結果到底多可信？再做一個樸素貝氏分類器

情境某疾病盛行率 1%，檢驗敏感度 95%、特異度 90%。病人檢驗陽性，真的患病的機率是多少？接著用同一個定理做一個「垃圾訊息」分類器。

對應考點條件機率 P(A|B) = P(A∩B)/P(B)貝氏定理：先驗、似然、邊際、後驗貝氏分類器
Python
# ── 一、貝氏定理手算 ─────────────────────────────
prior = 0.01            # P(病)：先驗（盛行率）
sens  = 0.95            # P(陽|病)：似然（敏感度）
spec  = 0.90            # P(陰|無病)：特異度 → P(陽|無病) = 1 - spec
p_pos = sens*prior + (1-spec)*(1-prior)      # 邊際機率 P(陽)
post  = sens*prior / p_pos                   # 後驗 P(病|陽)
print(f"P(陽性)        = {p_pos:.4f}")
print(f"P(患病 | 陽性) = {post:.4f}  → 陽性者只有約 {post*100:.1f}% 真的患病")
post2 = sens*post / (sens*post + (1-spec)*(1-post))   # 第二次檢驗：後驗變新的先驗
print(f"連續兩次陽性   = {post2:.4f}")

# ── 二、樸素貝氏分類器（詞袋 + 多項式 NB）─────────
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB
msgs = ["免費 中獎 點擊 領取", "限時 免費 優惠 點擊", "中獎 通知 立即 領取",
        "會議 下午 三點 討論", "請 回覆 會議 時間",   "下午 討論 專案 進度"]
y = [1, 1, 1, 0, 0, 0]                        # 1 = 垃圾訊息
vec = CountVectorizer(token_pattern=r"[^ ]+")  # 已先用空白斷詞
X = vec.fit_transform(msgs)
nb = MultinomialNB(alpha=1.0).fit(X, y)        # alpha=1：拉普拉斯平滑，避免機率為 0
words = vec.get_feature_names_out()
p_spam = {w: round(float(p), 3) for w, p in zip(words, __import__('numpy').exp(nb.feature_log_prob_[1]))}
print("\nP(詞 | 垃圾) 前 5：", sorted(p_spam.items(), key=lambda kv: -kv[1])[:5])
for t in ["免費 領取", "會議 進度", "免費 會議"]:
    p = nb.predict_proba(vec.transform([t]))[0, 1]
    print(f"「{t}」 是垃圾訊息的後驗機率 = {p:.3f}")

🔍 結果解讀
  • 盛行率只有 1% 時，即使檢驗很準，陽性者真正患病的機率也不到一成：先驗（基本率）會大幅影響後驗，這是貝氏推論最常考的直覺。
  • 第二次檢驗把第一次的後驗當成新的先驗，機率才跳到四成多：「後驗變先驗」就是貝氏更新。
  • 樸素貝氏假設每個詞彼此獨立，把 P(詞|類別) 相乘再乘先驗；alpha 平滑讓沒看過的詞不會把整個機率乘成 0。
💡 延伸練習把 prior 改成 0.30（高風險族群）再跑一次，看 P(患病|陽性) 變成多少；也試試把 alpha 改成 0.01，觀察「免費 會議」這種混合訊息的機率怎麼變。
範例 2

偏態與峰度：右偏的金額資料要不要取對數？

情境電商訂單金額通常「多數小額、少數超大額」。先算偏態、峰度判斷分佈形狀，再比較對數轉換與 Box-Cox 轉換後的效果。

對應考點期望值、變異數、標準差偏態：正偏右尾長峰度：常態 = 3（Pearson）對數／Box-Cox 轉換
Python
import numpy as np
from scipy import stats
rng = np.random.default_rng(42)
amount = rng.lognormal(mean=6.5, sigma=0.8, size=2000)     # 右偏的訂單金額

def describe(x, name):
    sk = stats.skew(x)
    ku = stats.kurtosis(x, fisher=False)   # fisher=False → Pearson 定義，常態分佈 = 3
    print(f"{name:10s} 平均={x.mean():9.1f} 中位數={np.median(x):9.1f} 標準差={x.std():9.1f} "
          f"偏態={sk:6.2f} 峰度={ku:6.2f}")

describe(amount, "原始金額")
describe(np.log(amount), "log 轉換")
bc, lam = stats.boxcox(amount)             # 自動找最佳 λ
describe(bc, f"Box-Cox")
print(f"\nBox-Cox 找到的 λ = {lam:.3f}（λ→0 即接近對數轉換）")
# 常態性檢定（Shapiro-Wilk）：p 越大越像常態
for name, x in [("原始", amount), ("log", np.log(amount)), ("Box-Cox", bc)]:
    print(f"Shapiro p 值 {name:8s} = {stats.shapiro(x[:500]).pvalue:.3f}")
# 平均 vs 中位數的位置關係也能判斷偏態方向
print("\n平均 > 中位數 → 正偏（右尾長）：", amount.mean() > np.median(amount))

Box-Cox    平均=      6.9 中位數=      6.9 標準差=      0.9 偏態=  0.00 峰度=  3.00

Box-Cox 找到的 λ = 0.020（λ→0 即接近對數轉換）
Shapiro p 值 原始       = 0.000
Shapiro p 值 log      = 0.633

🔍 結果解讀
  • 原始金額偏態為正、峰度遠大於 3：右尾又長又厚，平均被少數大單拉高、明顯高於中位數。
  • 取對數後偏態接近 0、峰度接近 3，Shapiro p 值明顯變大：對數轉換是處理右偏資料最常用的方法，Box-Cox 則是「自動挑指數」的一般化版本。
  • 指引強調偏態／峰度是決定「要不要轉換、要不要標準化」的依據：線性模型、距離型模型（KNN、SVM）對這類長尾很敏感，樹模型則較不在意。
💡 延伸練習把 sigma 改成 0.2（右偏變輕微），看 Box-Cox 的 λ 是否不再接近 0、對數轉換是否反而過度修正。

範例 3

向量、矩陣與最小平方法：ŷ = Xθ 從頭算一次

情境用兩位使用者的偏好向量算相似度，再用正規方程 θ = (XᵀX)⁻¹Xᵀy 解線性迴歸，最後看一個離群點怎麼把擬合線拉歪。

對應考點點積與餘弦相似度L2 範數矩陣乘法、轉置、求逆／偽逆OLS：誤差平方和最小離群點扭曲擬合
Python
import numpy as np
np.set_printoptions(precision=3, suppress=True)
# ── 向量：點積、範數、餘弦相似度 ───────────────
u = np.array([5, 4, 1, 0])     # 使用者 A 對四部電影的評分
v = np.array([4, 5, 0, 1])     # 使用者 B
w = np.array([0, 1, 5, 4])     # 使用者 C
cos = lambda a, b: a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
print(f"u·v = {u @ v},  ||u||₂ = {np.linalg.norm(u):.3f}")
print(f"cos(A,B) = {cos(u, v):.3f}   cos(A,C) = {cos(u, w):.3f}  → A 與 B 口味相近")

# ── 矩陣：線性迴歸的正規方程 ─────────────────
rng = np.random.default_rng(0)
x = np.linspace(0, 10, 12)
y = 3 + 2 * x + rng.normal(0, 1, 12)          # 真實關係 y = 3 + 2x + 雜訊
X = np.column_stack([np.ones_like(x), x])     # 設計矩陣：第一欄全 1 代表截距
theta = np.linalg.inv(X.T @ X) @ X.T @ y      # θ = (XᵀX)⁻¹ Xᵀ y
print(f"\nX 形狀 {X.shape}，XᵀX 形狀 {(X.T @ X).shape}")
print("正規方程 θ (截距, 斜率) =", theta)
print("偽逆 pinv 解          =", np.linalg.pinv(X) @ y, " ← 不可逆時仍可用")
from sklearn.linear_model import LinearRegression
lr = LinearRegression().fit(x.reshape(-1, 1), y)
print(f"sklearn               = [{lr.intercept_:.3f} {lr.coef_[0]:.3f}]")
sse = ((X @ theta - y) ** 2).sum()
print(f"誤差平方和 SSE = {sse:.3f}")

# ── 一個離群點的影響 ───────────────────────────
y_out = y.copy(); y_out[-1] += 40             # 最後一點被灌水 40
theta_out = np.linalg.pinv(X) @ y_out
print("\n加入離群點後的 θ =", theta_out, " ← 斜率與截距都被拉偏")
執行結果

cos(A,B) = 0.952   cos(A,C) = 0.214  → A 與 B 口味相近

正規方程 θ (截距, 斜率) = [3.356 1.933]

sklearn               = [3.356 1.933]

🔍 結果解讀
  • 餘弦相似度只看方向、不看長度，所以常用來比對偏好或文字向量；點積則同時受長度影響。
  • 正規方程、偽逆與 scikit-learn 三種解法得到一樣的 θ，驗證線性迴歸的本質就是「把 y 投影到 X 的欄空間」。
  • 一個離群點就能把 OLS 的斜率和截距拉偏，因為平方誤差對大殘差懲罰極重，這是指引提到「離群點會扭曲擬合」的直接示範。
💡 延伸練習試著把 X 多加一欄 2*x（與現有欄共線），看 inv 是否報錯而 pinv 仍能給出解。
範例 4

矩陣分解：用特徵值分解做 PCA，用 SVD 做低秩推薦

情境先把 3 維相關資料用共變異矩陣的特徵值分解投影到 2 維，和 scikit-learn 的 PCA 對照；再用 SVD 的低秩近似把使用者×商品評分矩陣壓縮、預測喜好。

對應考點特徵值分解 A = QΛQᵀ（PCA）SVD X = UΣVᵀ（推薦、LSA）解釋變異比例降維：去雜訊與共線性
Python
import numpy as np
np.set_printoptions(precision=3, suppress=True)
rng = np.random.default_rng(1)
# ── PCA：共變異矩陣的特徵值分解 ─────────────────
t = rng.normal(size=200)
X = np.column_stack([t, 0.8*t + rng.normal(0, .3, 200), -0.5*t + rng.normal(0, .3, 200)])
Xc = X - X.mean(axis=0)                       # 先中心化
C = Xc.T @ Xc / (len(X) - 1)                  # 共變異矩陣（3×3）
vals, vecs = np.linalg.eigh(C)                # 對稱矩陣用 eigh
order = np.argsort(vals)[::-1]; vals, vecs = vals[order], vecs[:, order]
ratio = vals / vals.sum()
print("特徵值 Λ      =", vals)
print("解釋變異比例  =", ratio, f"→ 前 2 個主成分解釋 {ratio[:2].sum():.1%}")
Z = Xc @ vecs[:, :2]                          # 投影到前 2 個主成分
from sklearn.decomposition import PCA
pca = PCA(n_components=2).fit(X)
print("sklearn 比例  =", pca.explained_variance_ratio_)
print("兩者投影是否一致（允許正負號翻轉）：",
      np.allclose(np.abs(Z), np.abs(pca.transform(X)), atol=1e-6))

# ── SVD：評分矩陣的低秩近似（推薦系統）─────────
R = np.array([[5, 4, 0, 1, 1],     # 列 = 使用者，欄 = 商品，0 代表未評分
              [4, 5, 1, 0, 1],
              [1, 1, 0, 5, 4],
              [0, 1, 1, 4, 5],
              [5, 5, 0, 1, 0]], dtype=float)
U, S, Vt = np.linalg.svd(R, full_matrices=False)
print("\n奇異值 Σ =", S)
k = 2
R2 = U[:, :k] * S[:k] @ Vt[:k]               # 只保留前 2 個奇異值重建
print(f"rank-{k} 重建（四捨五入）：\n", R2.round(1))
print("使用者 1 未評分的商品 3 預測分數 =", round(R2[0, 2], 2), "；商品 5 =", round(R2[4, 4], 2))

🔍 結果解讀
  • 特徵值的大小就是每個主成分的變異量，前兩個主成分就解釋了九成以上，第三個幾乎是雜訊，所以能安全地從 3 維降到 2 維。
  • 手算的投影與 scikit-learn 的 PCA 一致（只差正負號），說明 PCA 真的就是「共變異矩陣的特徵值分解」。
  • 評分矩陣只有前兩個奇異值明顯，保留 rank-2 就能重建出主要結構，連未評分的格子也有預測值，這正是 SVD 用於推薦與潛在語意分析（LSA）的原理。
💡 延伸練習把 k 改成 1 或 4，比較重建矩陣與原矩陣的差距（np.abs(R2 - R).mean()），感受「低秩 = 去雜訊」與「秩太低 = 失真」的權衡。

範例 5

五種優化器同台：GD、Momentum、Adagrad、RMSprop、Adam

情境在兩個碗型損失函數上比較五種優化器各要幾步才收斂：碗 A 兩個方向彎曲程度差 10 倍，碗 B 差 1000 倍（一個方向幾乎是平的）。順便看學習率太高會發生什麼事。

對應考點目標函數、決策變數、可行域凸函數必得全域最佳解GD／SGD／Momentum／Adagrad／RMSprop／Adam學習率過高致震盪發散收斂判準：梯度趨近零
Python
import numpy as np
bowls = {"碗A x²+10y²":      (lambda p: p[0]**2 + 10*p[1]**2,      lambda p: np.array([2*p[0], 20*p[1]])),
         "碗B 0.01x²+10y²":  (lambda p: 0.01*p[0]**2 + 10*p[1]**2, lambda p: np.array([0.02*p[0], 20*p[1]]))}

def optimize(f, grad, method, lr=0.05, steps=2000, tol=1e-3):
    p = np.array([5.0, 2.0]); m = np.zeros(2); v = np.zeros(2); b1, b2, eps = 0.9, 0.999, 1e-8
    for t in range(1, steps + 1):
        g = grad(p)
        if np.linalg.norm(g) < tol:                          # 收斂判準：梯度趨近零
            return t
        if method == "GD":         p = p - lr * g
        elif method == "Momentum": m = b1*m + g;             p = p - lr * m          # 累積方向
        elif method == "Adagrad":  v = v + g**2;             p = p - lr * g / (np.sqrt(v) + eps)   # 分母只增不減
        elif method == "RMSprop":  v = b2*v + (1-b2)*g**2;   p = p - lr * g / (np.sqrt(v) + eps)   # 滑動平均
        elif method == "Adam":
            m = b1*m + (1-b1)*g; v = b2*v + (1-b2)*g**2
            p = p - lr * (m/(1-b1**t)) / (np.sqrt(v/(1-b2**t)) + eps)   # 一階+二階動量，含偏差修正
        if not np.isfinite(f(p)) or f(p) > 1e12:
            return None                                        # 發散
    return steps + 1                                           # 未收斂

print(f"{'方法':10s}" + "".join(f"{n:>18s}" for n in bowls))
for method in ["GD", "Momentum", "Adagrad", "RMSprop", "Adam"]:
    row = f"{method:10s}"
    for f, grad in bowls.values():
        t = optimize(f, grad, method)
        row += f"{'發散' if t is None else '>2000 未收斂' if t > 2000 else f'{t} 步':>18s}"
    print(row)

print("\n學習率對 GD 的影響（碗A 的 y 方向曲率 20 → 穩定條件 lr < 2/20 = 0.1）：")
fA, gA = bowls["碗A x²+10y²"]
for lr in [0.01, 0.05, 0.09, 0.11]:
    t = optimize(fA, gA, "GD", lr=lr)
    print(f"  lr={lr:<5} → {'發散' if t is None else f'{t} 步收斂'}")

🔍 結果解讀
  • 碗 A 裡純梯度下降 89 步就收斂，但碗 B 的 x 方向梯度只有 0.02x，GD 用同一個學習率走了 2000 步還到不了：固定學習率無法同時照顧「很陡」與「很平」的方向。
  • RMSprop 與 Adam 把每個座標的梯度除以自己的歷史均方根，等於「每個方向有自己的學習率」，所以在碗 B 幾乎不受影響；Momentum 靠累積方向也加速了，但仍要四百多步。
  • Adagrad 兩個碗都卡住：它的分母把歷史梯度平方一直累加，學習率過度衰減到幾乎走不動，這就是指引點出的 Adagrad 缺點，RMSprop 用滑動平均修正了它。
  • Adam 在碗 A 反而比 GD 慢：自適應方法每步最多走約 lr 的距離，從 5 走到 0 至少要上百步；它的強項是「不怕尺度差異」，不是在簡單凸碗上比 GD 快。
  • 學習率超過 2/曲率（這裡是 0.1）時 GD 直接發散：學習率過高會震盪甚至發散，是訓練不穩定最常見的原因。

範例 6

損失函數怎麼選：MSE、MAE、Huber 與交叉熵、Focal Loss

情境同一組預測有一個離群誤差，比較三種迴歸損失的反應；再比較分類時「答對很有信心」「答錯很有信心」的交叉熵，以及 Focal Loss 如何壓低簡單樣本的權重。

對應考點迴歸：MSE、MAE、Huber分類：交叉熵Focal Loss：資料不平衡離群值敏感度
Python
import numpy as np
y    = np.array([10, 12, 14, 16, 18.0])
pred = np.array([11, 11, 15, 15, 18.0])
mse   = lambda y, p: np.mean((y - p)**2)
mae   = lambda y, p: np.mean(np.abs(y - p))
def huber(y, p, d=1.0):
    r = np.abs(y - p)
    return np.mean(np.where(r <= d, 0.5*r**2, d*(r - 0.5*d)))   # 小誤差像 MSE，大誤差像 MAE
print(f"{'情境':12s}{'MSE':>8s}{'MAE':>8s}{'Huber':>8s}")
print(f"{'一般誤差':12s}{mse(y,pred):8.2f}{mae(y,pred):8.2f}{huber(y,pred):8.2f}")
pred_out = pred.copy(); pred_out[2] = 35       # 一筆預測大錯
print(f"{'含一個離群':12s}{mse(y,pred_out):8.2f}{mae(y,pred_out):8.2f}{huber(y,pred_out):8.2f}")

# ── 二元交叉熵 ──────────────────────────────
bce = lambda yt, p: -(yt*np.log(p) + (1-yt)*np.log(1-p))
print("\n交叉熵（真實標籤 = 1）：")
for p in [0.99, 0.7, 0.5, 0.3, 0.01]:
    print(f"  預測 P(y=1)={p:.2f} → loss = {bce(1, p):6.3f}")

# ── Focal Loss：(1-p_t)^γ 把「已經答得很好的簡單樣本」權重壓低 ──
def focal(yt, p, gamma=2.0):
    pt = np.where(yt == 1, p, 1 - p)
    return -(1 - pt)**gamma * np.log(pt)
print("\n交叉熵 vs Focal(γ=2)：")
for p in [0.95, 0.6, 0.2]:
    print(f"  p_t={p:.2f}  CE={bce(1,p):.3f}  Focal={focal(1,p):.4f}  （比例 {focal(1,p)/bce(1,p):.3f}）")

  • 一個離群誤差讓 MSE 暴增好幾倍，MAE 只線性增加，Huber 介於兩者之間：MSE 對離群值最敏感，要「抗離群」就選 MAE 或 Huber。
  • 交叉熵在「很有信心卻答錯」（p=0.01）時損失極大，在「很有信心且答對」時接近 0，這就是它能逼模型校準機率的原因。
  • Focal Loss 把容易樣本（p_t=0.95）的損失壓到原本的千分之幾，困難樣本幾乎不變，所以能讓模型把注意力放在稀少類別上，用於資料不平衡。

def run(X, ytrue, name):
    X = StandardScaler().fit_transform(X)
    algos = {"K-means(k=2或3)": KMeans(n_clusters=len(set(ytrue)), n_init=10, random_state=0),
             "階層式(ward)":    AgglomerativeClustering(n_clusters=len(set(ytrue))),

關聯規則：從購物籃算支持度、信賴度與提升度

情境10 筆交易紀錄，找出常一起買的商品組合，並判斷「買尿布的人也買啤酒」是真的關聯還是啤酒本來就熱銷。

對應考點關聯規則：Apriori支持度 Support信賴度 Confidence提升度 Lift（> 1 才有正關聯）
Python
from itertools import combinations
T = [{"尿布", "啤酒", "牛奶"}, {"尿布", "啤酒"}, {"牛奶", "麵包"}, {"尿布", "啤酒", "麵包"}, {"牛奶", "麵包", "雞蛋"},
     {"尿布", "牛奶"}, {"麵包", "雞蛋"}, {"尿布", "啤酒", "牛奶", "麵包"}, {"牛奶", "雞蛋"}, {"麵包", "牛奶"}]
N = len(T)
support = lambda items: sum(items <= t for t in T) / N      # 含該組合的交易比例

# Apriori：先找頻繁 1-項集，再只用頻繁項組合成 2-項集（剪枝）
min_sup = 0.3                                                # 至少出現 3/10 次
items = sorted({i for t in T for i in t})
L1 = [frozenset([i]) for i in items if support({i}) >= min_sup]
print("頻繁 1-項集：", {tuple(s)[0]: round(support(s), 3) for s in L1})
L2 = [a | b for a, b in combinations(L1, 2) if support(a | b) >= min_sup]
print("頻繁 2-項集：", {" + ".join(sorted(s)): round(support(s), 3) for s in L2})

print(f"\n{'規則':14s}{'支持度':>7s}{'信賴度':>7s}{'提升度':>7s}")
for pair in L2:
    for a in pair:
        b = pair - {a}
        conf = support(pair) / support({a})                  # P(B|A)
        lift = conf / support(b)                             # P(B|A) / P(B)
        print(f"{a} → {tuple(b)[0]:8s}{support(pair):7.3f}{conf:7.3f}{lift:7.2f}")

範例 11

感知器解不了 XOR，兩層神經網路可以：手刻前向與反向傳播

情境先讓單層感知器學 XOR（必定失敗），再用 numpy 寫一個 2-4-1 的小網路，用連鎖律手算梯度，看損失一路下降。

對應考點人工神經元 Z = Σwx + b感知器無法解 XOR激活函數引入非線性前向傳播 vs 反向傳播（連鎖律）
Python
import numpy as np
X = np.array([[0,0],[0,1],[1,0],[1,1]], dtype=float)
y = np.array([[0],[1],[1],[0]], dtype=float)           # XOR

# ── 單層感知器（線性 + 階梯函數）────────────────
w, b = np.zeros(2), 0.0
for epoch in range(50):
    for xi, yi in zip(X, y[:, 0]):
        pred = 1.0 if xi @ w + b > 0 else 0.0
        w += 0.1 * (yi - pred) * xi; b += 0.1 * (yi - pred)   # 感知器學習規則
acc = np.mean([(1.0 if xi @ w + b > 0 else 0.0) == yi for xi, yi in zip(X, y[:, 0])])
print(f"感知器 50 輪後對 XOR 的準確率 = {acc:.2f}（一條直線切不開）")

# ── 2-4-1 多層感知器（sigmoid）────────────────
sig = lambda z: 1 / (1 + np.exp(-z))
rng = np.random.default_rng(0)
W1, b1 = rng.normal(0, 1, (2, 4)), np.zeros((1, 4))
W2, b2 = rng.normal(0, 1, (4, 1)), np.zeros((1, 1))
lr = 1.0
for epoch in range(1, 5001):
    # 前向傳播
    Z1 = X @ W1 + b1;  A1 = sig(Z1)                     # 隱藏層
    Z2 = A1 @ W2 + b2; A2 = sig(Z2)                     # 輸出層（機率）
    loss = -np.mean(y*np.log(A2) + (1-y)*np.log(1-A2))  # 二元交叉熵
    # 反向傳播（連鎖律，由輸出層往回算）
    dZ2 = A2 - y                                        # ∂loss/∂Z2（交叉熵 + sigmoid 的簡潔結果）
    dW2 = A1.T @ dZ2 / 4;      db2 = dZ2.mean(0, keepdims=True)
    dA1 = dZ2 @ W2.T
    dZ1 = dA1 * A1 * (1 - A1)                           # sigmoid 導數 σ(1-σ)
    dW1 = X.T @ dZ1 / 4;       db1 = dZ1.mean(0, keepdims=True)
    W2 -= lr*dW2; b2 -= lr*db2; W1 -= lr*dW1; b1 -= lr*db1
    if epoch in (1, 100, 500, 1000, 5000):
        print(f"epoch {epoch:5d}  loss = {loss:.4f}")
print("MLP 預測：", sig(sig(X @ W1 + b1) @ W2 + b2).round(2).ravel(), " ← 目標 [0 1 1 0]")

print("\n常見激活函數在 z = -2, 0, 2 的值：")
z = np.array([-2., 0., 2.])
print("  sigmoid", sig(z).round(3), " tanh", np.tanh(z).round(3), " ReLU", np.maximum(0, z))

🔍 結果解讀
  • 感知器只是一條直線（超平面），XOR 的四個點無法用一條線分開，準確率卡在 0.5 左右：這就是 1969 年讓神經網路研究停滯的著名限制。
  • 加一層隱藏層＋非線性激活函數後，網路先把輸入映射到新空間，再切一刀就能分開，損失從 0.7 降到接近 0。
  • 反向傳播就是連鎖律：先算輸出層的誤差 dZ2，再乘上 W2 與 sigmoid 導數得到隱藏層的誤差，一層層往回傳；用交叉熵搭配 sigmoid 時 dZ2 剛好等於「預測 − 真實」。

範例 12

Transformer 的心臟：自注意力 Q、K、V 與位置編碼

情境用 4 個詞的小句子，手算一次縮放點積注意力：每個詞對其他詞的注意力權重是多少？再加上 GPT 式的因果遮罩與 sin/cos 位置編碼。

對應考點Transformer：自注意力 Q/K/V縮放點積 softmax(QKᵀ/√d)V位置編碼BERT（編碼器，雙向）vs GPT（解碼器，因果遮罩）
Python
import numpy as np
np.set_printoptions(precision=2, suppress=True)
tokens = ["貓", "追", "老鼠", "跑"]
rng = np.random.default_rng(3)
d = 4                                            # 嵌入維度
E = rng.normal(size=(4, d))                      # 4 個詞的嵌入向量（實際由模型學出）
Wq, Wk, Wv = (rng.normal(size=(d, d)) for _ in range(3))
Q, K, V = E @ Wq, E @ Wk, E @ Wv                 # 查詢、鍵、值

def softmax(z):
    z = z - z.max(axis=-1, keepdims=True)
    return np.exp(z) / np.exp(z).sum(axis=-1, keepdims=True)

scores = Q @ K.T / np.sqrt(d)                    # 相似度分數，÷√d 避免數值過大
A = softmax(scores)                              # 每一列是一個詞對所有詞的注意力權重
print("注意力權重（列 = 查詢詞，欄 = 被注意的詞）：")
for t, row in zip(tokens, A):
    print(f"  {t:3s}", row, " 最注意 →", tokens[int(row.argmax())])
print("每列總和 =", A.sum(axis=1))
out = A @ V                                      # 加權求和後的新表示（形狀不變）
print("輸出形狀", out.shape, "（每個詞都變成『看過整句』的向量）")

# ── 因果遮罩（GPT／解碼器）：只能看自己與左邊 ──
mask = np.triu(np.ones((4, 4)), k=1).astype(bool)
A_causal = softmax(np.where(mask, -1e9, scores))
print("\n因果遮罩後的權重（上三角被遮成 0）：\n", A_causal)

# ── 正弦位置編碼：讓模型知道詞序 ───────────────
pos = np.arange(4)[:, None]; i = np.arange(d)[None, :]
angle = pos / np.power(10000, (2 * (i // 2)) / d)
PE = np.where(i % 2 == 0, np.sin(angle), np.cos(angle))
print("\n位置編碼 PE（每個位置一個獨特向量，加到嵌入上）：\n", PE)

🔍 結果解讀
  • 注意力權重由查詢（Q）與鍵（K）的點積決定，經 softmax 後每列總和為 1，再用它對值（V）加權求和：輸出形狀和輸入一樣，但每個詞的向量已經「融合了整句的資訊」。
  • ÷√d 是「縮放」的由來：維度越高點積越大，不縮放的話 softmax 會過度尖銳、梯度消失。
  • BERT 式編碼器讓每個詞看整句（雙向），GPT 式解碼器用上三角遮罩只看左邊，才能逐字生成；位置編碼則補上自注意力本身沒有的「順序」資訊。

  • 三種離群值偵測抓到的筆數不同：Z 分數用平均與標準差，本身會被離群值拉動；IQR 用分位數較穩健；Isolation Forest 不假設分佈，但要給 contamination。
  • Min-Max 的 1.0 被離群值佔走，一般值全被擠到 0.2 附近；Z-score 的平均與標準差被離群值拉動；Robust 用中位數與 IQR，中位數剛好落在 0、一般值維持正常尺度、離群值顯得更極端（反而更容易被看出來）：有離群值時優先用 Robust Scaling。
  • 把小時直接當數字會讓 23 點與 0 點相距 23；sin/cos 編碼後兩者的距離與 12 點、13 點一樣近，這就是週期特徵編碼的目的。
💡 延伸練習Target Encoding 若在整個資料集上算再拿去訓練，會把 y 洩漏進特徵。試著只用訓練集算 city_target，再套到測試集，比較兩種做法的測試分數。

import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import (confusion_matrix, accuracy_score, precision_score, recall_score, f1_score,
                             roc_auc_score, mean_squared_error, mean_absolute_error, r2_score)
X, y = make_classification(n_samples=4000, n_features=10, weights=[0.95, 0.05], flip_y=0.02, random_state=0)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.5, random_state=0, stratify=y)
clf = LogisticRegression(max_iter=1000).fit(Xtr, ytr)
proba = clf.predict_proba(Xte)[:, 1]
print(f"測試集正類比例 = {yte.mean():.1%}  → 全部猜 0 的準確率就有 {1 - yte.mean():.1%}（準確率在不平衡時會誤導）")

def report(th):
    pred = (proba >= th).astype(int)
    tn, fp, fn, tp = confusion_matrix(yte, pred).ravel()
    prec = tp / (tp + fp) if tp + fp else 0.0; rec = tp / (tp + fn)
    f1 = 2*prec*rec / (prec + rec) if prec + rec else 0.0
    print(f"門檻 {th:.2f} | TP={tp:3d} FP={fp:3d} FN={fn:3d} TN={tn:4d} | 準確率={accuracy_score(yte,pred):.3f} "
          f"Precision={prec:.3f} Recall={rec:.3f} F1={f1:.3f}")
    assert abs(prec - precision_score(yte, pred)) < 1e-9 and abs(rec - recall_score(yte, pred)) < 1e-9
for th in [0.5, 0.3, 0.1]:
    report(th)
print(f"ROC-AUC = {roc_auc_score(yte, proba):.3f}（與門檻無關，衡量排序能力）")

# ── 迴歸指標 ────────────────────────────────
yt = np.array([3.0, 5.0, 7.0, 9.0, 11.0]); yp = np.array([2.5, 5.5, 6.0, 9.5, 13.0])
mse = mean_squared_error(yt, yp)
print(f"\n迴歸：MSE={mse:.3f}  RMSE={mse**0.5:.3f}  MAE={mean_absolute_error(yt, yp):.3f}  R²={r2_score(yt, yp):.3f}")

範例 17

交叉驗證與早停：K-fold、分層 K-fold、LOOCV 的成本，以及 patience 怎麼用

情境不平衡資料上比較普通 K-fold 與分層 K-fold 每折的正類比例；數一數 LOOCV 要訓練幾次；最後用梯度提升的逐步預測實作 patience 早停。

Python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import KFold, StratifiedKFold, LeaveOneOut, RepeatedKFold, cross_val_score, train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import log_loss
X, y = make_classification(n_samples=100, n_features=8, weights=[0.85, 0.15], random_state=1)
print(f"整體正類比例 = {y.mean():.2f}")
for name, cv in [("KFold", KFold(5, shuffle=True, random_state=0)), ("StratifiedKFold", StratifiedKFold(5, shuffle=True, random_state=0))]:
    ratios = [round(float(y[te].mean()), 2) for _, te in cv.split(X, y)]
    print(f"{name:16s} 各折驗證集正類比例 = {ratios}")

clf = LogisticRegression(max_iter=1000)
print(f"\n5-fold 準確率  = {cross_val_score(clf, X, y, cv=StratifiedKFold(5, shuffle=True, random_state=0)).mean():.3f}")
print(f"LOOCV 準確率   = {cross_val_score(clf, X, y, cv=LeaveOneOut()).mean():.3f}（訓練了 {LeaveOneOut().get_n_splits(X)} 次）")
rep = cross_val_score(clf, X, y, cv=RepeatedKFold(n_splits=5, n_repeats=10, random_state=0))
print(f"Repeated 5×10  = {rep.mean():.3f} ± {rep.std():.3f}（{len(rep)} 次，估計更穩）")

# ── 早停（Early Stopping）：驗證損失連續 patience 回合沒改善 min_delta 就停 ──
X2, y2 = make_classification(n_samples=1500, n_features=20, flip_y=0.15, random_state=0)
Xtr, Xva, ytr, yva = train_test_split(X2, y2, test_size=0.3, random_state=0)
gb = GradientBoostingClassifier(n_estimators=400, learning_rate=0.1, max_depth=3, random_state=0).fit(Xtr, ytr)
patience, min_delta, best, best_i, wait = 15, 1e-4, np.inf, 0, 0
for i, p in enumerate(gb.staged_predict_proba(Xva), start=1):      # 第 i 棵樹時的驗證預測
    loss = log_loss(yva, p[:, 1])
    if best - loss > min_delta: best, best_i, wait = loss, i, 0
    else:
        wait += 1
        if wait >= patience: break
print(f"\n早停：最佳驗證損失 {best:.4f} 出現在第 {best_i} 棵樹，第 {i} 棵時觸發停止（patience={patience}）")
print(f"對照：用完 400 棵樹的驗證損失 = {log_loss(yva, gb.predict_proba(Xva)[:, 1]):.4f}（持續訓練反而變差 → 過擬合）")

StratifiedKFold  各折驗證集正類比例 = [0.15, 0.15, 0.15, 0.15, 0.15]

🔍 結果解讀
  • 普通 K-fold 每折的正類比例忽高忽低，分層 K-fold 每折都接近整體比例，所以分類任務預設用分層抽樣，避免某折幾乎沒有正類。
  • LOOCV 要訓練 n 次（這裡 100 次），偏差最小但成本極高、估計變異也大；Repeated K-fold 用多次不同切法取平均，是穩定性與成本的折衷。
  • 梯度提升的驗證損失先降後升，早停在最佳點之後等 patience 回合沒改善就停下，比用完全部的樹更好：早停本質是一種正則化。

資料不平衡三招：類別權重、過採樣（手刻 SMOTE）、欠採樣

情境正類只佔 4% 的客戶流失資料。原始模型 Recall 很低，比較 class_weight、SMOTE 合成少數類、隨機欠採樣三種做法對 Recall／F1 的影響。

對應考點過採樣（SMOTE）欠採樣類別權重調整Recall 與 F1 的取捨
Python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import NearestNeighbors
from sklearn.metrics import recall_score, precision_score, f1_score
X, y = make_classification(n_samples=5000, n_features=8, weights=[0.96, 0.04], class_sep=0.5, random_state=3)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.4, random_state=0, stratify=y)
print(f"訓練集正類 {ytr.sum()} / {len(ytr)} 筆（{ytr.mean():.1%}）")

def smote(X, y, k=5, seed=0):
    """手刻 SMOTE：在少數類樣本與其鄰居之間插值，合成到與多數類一樣多"""
    rng = np.random.default_rng(seed)
    Xm = X[y == 1]; need = (y == 0).sum() - len(Xm)
    nn = NearestNeighbors(n_neighbors=k + 1).fit(Xm)
    idx = rng.integers(0, len(Xm), need)                              # 隨機挑少數類樣本
    nbr = nn.kneighbors(Xm[idx], return_distance=False)[:, 1:]        # 它的 k 個鄰居（排除自己）
    pick = nbr[np.arange(need), rng.integers(0, k, need)]
    synth = Xm[idx] + rng.random((need, 1)) * (Xm[pick] - Xm[idx])     # 線段上隨機一點
    return np.vstack([X, synth]), np.concatenate([y, np.ones(need, int)])

rng = np.random.default_rng(0)
maj = np.flatnonzero(ytr == 0); keep = rng.choice(maj, size=(ytr == 1).sum(), replace=False)
under = np.concatenate([keep, np.flatnonzero(ytr == 1)])
Xs, ys = smote(Xtr, ytr)
setups = {"原始":            (Xtr, ytr, {}),
          "class_weight":    (Xtr, ytr, {"class_weight": "balanced"}),
          "SMOTE 過採樣":     (Xs, ys, {}),
          "隨機欠採樣":        (Xtr[under], ytr[under], {})}
print(f"\n{'做法':14s}{'訓練筆數':>8s}{'Recall':>8s}{'Precision':>10s}{'F1':>7s}")
for name, (Xa, ya, kw) in setups.items():
    m = LogisticRegression(max_iter=1000, **kw).fit(Xa, ya); p = m.predict(Xte)
    print(f"{name:14s}{len(ya):8d}{recall_score(yte,p):8.3f}{precision_score(yte,p):10.3f}{f1_score(yte,p):7.3f}")

  • class_weight 不改資料、只在損失函數裡放大少數類的權重，最省事；SMOTE 在少數類樣本之間插值合成新點，比單純複製更不容易過擬合；欠採樣最快但丟掉大量多數類資訊。
  • F1 下降不代表做錯：漏掉一個流失客戶的成本遠高於多打一通挽留電話時，就該選 Recall 高的做法，指標要對應業務成本。SMOTE 只能在訓練集上做，測試集必須保持原始分佈。

範例 20

模型壓縮：剪枝與 INT8 量化對準確率與大小的影響

情境訓練一個小型 MLP，然後（1）把絕對值最小的 70% 權重剪成 0，（2）把 FP32 權重量化成 INT8，各自看準確率掉多少、模型小多少。

對應考點剪枝：結構化 vs 非結構化量化：FP32 → INT8知識蒸餾（教師→學生）概念邊緣裝置部署限制
Python
import numpy as np
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPClassifier
X, y = load_digits(return_X_y=True); X = X / 16.0
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=0, stratify=y)
mlp = MLPClassifier(hidden_layer_sizes=(64,), max_iter=400, random_state=0).fit(Xtr, ytr)
W = [w.copy() for w in mlp.coefs_]
n_param = sum(w.size for w in W)
print(f"原始 FP32 模型：{n_param} 個權重 ≈ {n_param*4/1024:.1f} KB，測試準確率 = {mlp.score(Xte, yte):.4f}")

def eval_with(weights):
    mlp.coefs_ = weights; return mlp.score(Xte, yte)

# ── 非結構化剪枝：全域絕對值最小的 r% 權重設為 0 ──
flat = np.concatenate([w.ravel() for w in W])
for r in [0.5, 0.7, 0.9]:
    th = np.quantile(np.abs(flat), r)
    Wp = [np.where(np.abs(w) < th, 0.0, w) for w in W]
    nz = sum(int((w != 0).sum()) for w in Wp)
    print(f"剪枝 {r:.0%}      ：非零權重 {nz:4d}（{nz/n_param:.0%}），稀疏儲存約 {nz*4/1024:4.1f} KB，準確率 = {eval_with(Wp):.4f}")

# ── 結構化剪枝：直接刪掉輸出權重範數最小的 32 個隱藏神經元 ──
norms = np.linalg.norm(W[1], axis=1); drop = np.argsort(norms)[:32]
Ws = [W[0].copy(), W[1].copy()]; Ws[0][:, drop] = 0; Ws[1][drop, :] = 0
print(f"結構化剪枝 32 個神經元：準確率 = {eval_with(Ws):.4f}（整列整欄歸零，硬體真的能跳過）")

# ── INT8 量化：每層一個縮放因子 s，w ≈ s * q，q 為 -127..127 的整數 ──
def quantize(w):
    s = np.abs(w).max() / 127
    q = np.clip(np.round(w / s), -127, 127).astype(np.int8)
    return s, q
Wq = []
for w in W:
    s, q = quantize(w); Wq.append(s * q.astype(np.float32))           # 反量化後拿來推論
err = np.mean([np.abs(a - b).mean() for a, b in zip(W, Wq)])
print(f"INT8 量化     ：≈ {n_param*1/1024:.1f} KB（1/4 大小），平均權重誤差 {err:.5f}，準確率 = {eval_with(Wq):.4f}")
mlp.coefs_ = W

  • 這些技術就是為了邊緣裝置、即時推論的資源限制而生；知識蒸餾則是另一條路：用大模型（教師）的輸出機率來訓練一個小模型（學生）。

import hashlib, numpy as np, pandas as pd
df = pd.DataFrame({"name": ["王小明", "李美玲", "陳大文", "林雅婷", "張志豪", "黃淑芬"],
                   "zip": ["10041", "10042", "10651", "10652", "10043", "10653"],
                   "age": [34, 37, 52, 58, 31, 55],
                   "disease": ["流感", "流感", "糖尿病", "高血壓", "流感", "糖尿病"]})
# 1) 直接識別欄：遮蔽或刪除；需要跨表串接時用加鹽雜湊（假名化）
salt = "project-2026"
df["name_masked"] = df.name.map(lambda s: s[0] + "○" * (len(s) - 1))
df["pid"] = df.name.map(lambda s: hashlib.sha256((salt + s).encode()).hexdigest()[:10])
# 2) 準識別欄：泛化（郵遞區號取前 3 碼、年齡分桶）
df["zip_g"] = df.zip.str[:3] + "**"
df["age_g"] = pd.cut(df.age, bins=[0, 40, 60, 120], labels=["≤40", "41-60", ">60"]).astype(str)
print(df[["name_masked", "pid", "zip_g", "age_g", "disease"]].to_string(index=False))

# 3) K-匿名檢查：每一組準識別值至少要有 K 筆
qi = ["zip_g", "age_g"]
grp = df.groupby(qi, observed=True)
sizes = grp.size()
print(f"\n各等價類大小：{sizes.to_dict()}  → K = {sizes.min()}（K-匿名達成 K={sizes.min()}）")
# L-多樣性：每個等價類內敏感值的種類數
ldiv = grp.disease.nunique()
print(f"各等價類疾病種類數：{ldiv.to_dict()}  → L = {ldiv.min()}（L=1 的那組只要知道等價類就知道疾病！）")

# 4) 差分隱私：對計數查詢加 Laplace(敏感度/ε) 雜訊
true = int((df.disease == "流感").sum())
rng = np.random.default_rng(0)
for eps in [0.1, 1.0, 10.0]:
    noisy = true + rng.laplace(0, 1/eps, 1000)          # 敏感度 = 1（一個人最多改變計數 1）
    print(f"ε={eps:4}: 真實流感人數 {true}，加噪回答平均 {noisy.mean():.2f}，標準差 {noisy.std():.2f}")

def fairness(pred, label):
    print(f"\n{label}   整體準確率 = {(pred == yte).mean():.3f}")
    rates = {}
    for grp in [0, 1]:
        m = gte == grp; p = pred[m]; t = yte[m]

    (sA, tA, fA), (sB, tB, fB) = rates[0], rates[1]
    print(f"  Demographic Parity 差 = {abs(sA-sB):.3f} | Equal Opportunity(TPR) 差 = {abs(tA-tB):.3f} | "
          f"Equalized Odds(FPR) 差 = {abs(fA-fB):.3f} | Disparate Impact = {min(sA,sB)/max(sA,sB):.3f} {'✔' if min(sA,sB)/max(sA,sB) >= 0.8 else '✘ 低於 80% 法則'}")

fairness((proba >= 0.5).astype(int), "① 原始模型（單一門檻 0.5）")

# 後處理：為 B 群體調低門檻，讓兩群的核准率拉近
thB = 0.5
while ((proba[gte == 1] >= thB).mean() < (proba[gte == 0] >= 0.5).mean()) and thB > 0.05:
    thB -= 0.01
pred_pp = np.where(gte == 1, proba >= thB, proba >= 0.5).astype(int)
fairness(pred_pp, f"② 後處理：A 門檻 0.5、B 門檻 {thB:.2f}")

# 前處理：特徵去偏——把收入與分數在「各群體內」分別標準化，抹掉群體間的平均差距
def debias(Xa, ga, ref_X, ref_g):
    out = Xa.astype(float).copy()
    for grp in [0, 1]:
        mu, sd = ref_X[ref_g == grp].mean(0), ref_X[ref_g == grp].std(0)
        out[ga == grp] = (Xa[ga == grp] - mu) / sd
    return out
clf_db = LogisticRegression().fit(debias(Xtr, gtr, Xtr, gtr), ytr)
fairness((clf_db.predict_proba(debias(Xte, gte, Xtr, gtr))[:, 1] >= 0.5).astype(int), "③ 前處理：特徵去偏後重訓")
