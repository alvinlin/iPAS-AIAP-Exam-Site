L221

第三章 機率統計基礎

先打統計地基：描述資料、理解隨機性、做嚴謹推論。

L221013.1 敘述性統計與資料摘要技術開啟 →
  • 集中趨勢測量
    • 算術平均（怕極端值）
    • 幾何平均（成長率、報酬率）
    • 調和平均（速率）
    • 眾數（類別資料）
    • 中位數（抗極端值）
  • 離散程度測量
    • 變異數 σ² ／標準差 σ
    • 全距（易受極端值影響）
    • 四分位數 Q1・Q2・Q3
    • IQR = Q3 − Q1
    • 箱形圖：鬚 = Q1 − 1.5×IQR ～ Q3 + 1.5×IQR
    • 附圖：箱形圖構造（指引 3-8）
  • 分佈形狀
    • 偏度：正偏（右尾長）> 0、負偏（左尾長）< 0
    • 峰度（Pearson，常態 = 3）：高峰 > 3、中峰 ≈ 3、扁平 < 3
    • 附圖：偏態、峰度（指引 3-11、3-12）
L221023.2 機率分佈與資料分佈模型開啟 →
  • 期望值與變異數
    • E(X)：長期加權平均
    • Var(X)：分散程度
    • 離散用 Σ、連續用 ∫
  • 兩種類型
    • 離散型：PMF，總和 = 1
    • 連續型：PDF，P(a ≤ X ≤ b) = ∫f(x)dx
  • 常見離散型分佈
    • 伯努利：E = p
    • 二項：E = np、Var = np(1−p)
    • 泊松：E = Var = λ
  • 常見連續型分佈
    • 常態：E = μ、Var = σ²，中央極限定理
    • 指數：E = 1/λ，無記憶性
    • 卡方：E = k、Var = 2k
    • 自由度 df
  • 分佈擬合與資料建模
    • 最大似然估計找參數
    • 先判斷離散或連續
    • 偏態長尾：對數常態、t 分佈
    • 檢查獨立性（自相關）
L221033.3 假設檢定與統計推論開啟 →
  • 參數估計
    • 點估計（無法反映不確定性）
    • 區間估計：95% 信賴區間的正確解讀
  • 假設檢定流程
    • 定 H₀／H₁ → 選檢定 → 定 α → 算 p 值 → 決策
    • α = 0.05／0.01／0.10
    • p ≤ α 拒絕 H₀；無法拒絕 ≠ 接受
    • 多重比較：Bonferroni 校正
  • 兩種錯誤類型
    • 型一錯誤（誤判）= α
    • 型二錯誤（漏判）= β
    • 檢定力 = 1 − β
    • 檢定力分析 (Power Analysis)
  • 常見統計檢定方法
    • 單樣本／獨立樣本／成對樣本 t 檢定
    • 單因子 ANOVA（事後 Tukey HSD）
    • 比例檢定、卡方檢定（Cramér's V）
    • Pearson（線性）／Spearman（單調）相關
    • 非參數：Mann-Whitney U、Kruskal-Wallis

自我檢核敘述統計只概括不推論；極端值多用中位數；p < α 拒絕 H₀；CLT 指「樣本平均數」趨近常態。

第四章 大數據處理技術

資料工程：從收集、清理、儲存，到分散式運算與管線。

L222014.1 數據收集與清理開啟 →
  • 常見資料來源與蒐集方式
    • 感測器／IoT：MQTT、Kafka
    • 系統日誌：Flume、Logstash、NiFi
    • API：RESTful + Airflow、Talend
    • 爬蟲：Scrapy、BeautifulSoup
    • 企業內部系統：Snowflake、BigQuery
  • 資料品質問題類型
    • 缺失值：MCAR／MAR／MNAR
    • 異常值：IQR、Z 分數、孤立森林
    • 重複值
    • 一致性錯誤（臺北／台北）
    • 邏輯錯誤（體溫 43°C）
  • 資料品質指標
    • 缺失率
    • 唯一值比率
    • 一致性比率
    • 異常值比率
    • 完整性比率
L222024.2 數據儲存與管理開啟 →
  • 三種資料型態與儲存
    • 結構化 → RDBMS（ACID）
    • 半結構化 → MongoDB、Elasticsearch
    • 非結構化 → S3、MinIO、HDFS
  • 分散式儲存與資料湖
    • 橫向擴充、容錯（Paxos、Raft）
    • 資料本地性
    • 資料湖：Schema-on-Read
    • 資料湖倉：Delta Lake、Iceberg、Hudi
  • 儲存效能優化與查詢加速
    • 分區、列式壓縮（Parquet、ORC）
    • 冷熱分層、欄位裁剪
    • 物化檢視、索引
    • Catalyst、Presto CBO
  • 一致性與版本管理
    • 強一致性 vs 最終一致性
    • ACID 四大特性
    • Time Travel、Incremental Query
  • 資料治理與存取控管
    • 元資料、Data Catalog、Data Lineage
    • RBAC／ABAC／PBAC／DAC
    • 稽核紀錄（GDPR、CCPA）
    • 零信任：最小權限、JIT
L222034.3 數據處理技術與工具開啟 →
  • 資料準備與轉換
    • 型別轉換、ISO 8601
    • 分箱：等寬、等頻、K-Means
    • Label／One-hot／Target Encoding
    • Min-Max、Z-score、Robust Scaling
  • 特徵工程
    • 防資料洩漏
    • 特徵選擇：Filter／Wrapper／Embedded
    • 交互、時間、聚合特徵
    • 資料增強、SMOTE
  • 分散式運算框架
    • Hadoop MapReduce：批次
    • Spark：記憶體內運算
    • Flink：原生串流
    • Beam：統一抽象
  • 資料處理管線
    • 可重現、容錯、擴充、可觀測
    • Airflow、Luigi、Prefect、Kubeflow
    • CI/CD、監控、容器化

自我檢核感測器資料屬高頻串流；JSON/XML 適合文件型 NoSQL；資料湖不需預先定義結構；即時監控用串流處理。

L223

第五章 大數據分析方法與工具

把整理好的資料變成洞察：統計、分析方法、視覺化。

L223015.1 統計學在大數據中的應用開啟 →
  • 敘述統計的挑戰
    • 資料無法全載入記憶體
    • 長尾偏態：改用中位數、分位數
    • 多型態資料難統一
    • 罕見異常被稀釋
    • 資料動態變化
  • 統計推論的限制與風險
    • 樣本非隨機，偏誤被放大
    • p 值膨脹 → 看效果量
    • 多重檢定：Bonferroni、FDR
    • 樣本非獨立
    • 母體定義不清
  • 實務應用情境
    • 行銷：邏輯迴歸、K-means
    • 金融：ARIMA、蒙地卡羅
    • 醫療：Kaplan-Meier、Cox
    • 製造：SPC 控制圖
    • 資安、政策、智慧城市
L223025.2 常見的大數據分析方法開啟 →
  • 近似描述性統計
    • t-digest（分位數）
    • Histogram Sketch
    • Count-Min Sketch（頻率）
    • Welford 線上均值／變異數
  • 時序分析
    • 移動平均、指數平滑
    • ARIMA、SARIMA
    • Prophet、LSTM、Transformer
  • 網路分析
    • 中心性：Degree、Betweenness、PageRank
    • 社群偵測：Louvain
    • 鏈結預測：GNN
    • Neo4j、NetworkX
  • 文字分析
    • 斷詞、詞形還原 vs 詞幹提取
    • TF-IDF
    • Word2Vec、GloVe、FastText
    • BERT、RoBERTa
    • LDA、NER
  • 地理空間分析
    • 點／線／面資料
    • 熱點：KDE、Getis-Ord Gi*
    • DBSCAN
    • 地理加權迴歸 GWR
  • 異常偵測
    • Z-score、IQR
    • LOF、KNN
    • Isolation Forest
    • PyOD
L223035.3 數據可視化工具開啟 →
  • 依資料型態選圖
    • 分佈：直方圖、箱型圖、KDE
    • 關聯：散佈圖、相關矩陣、熱力圖
    • 類別：長條、堆疊長條、圓餅
    • 時間：折線圖
    • 附圖：10 種圖表範例（指引 5-30～5-39）
  • 平台工具分類
    • 內建報表：Excel、Google Sheets
    • 程式庫：Matplotlib、Plotly、D3.js
    • 輕量 BI：Metabase、Superset、Grafana
    • 商業平台：Tableau、Power BI
  • 設計原則
    • 以閱讀者為中心
    • 圖表符合資料型態
    • 簡化、去冗餘
    • 合理用色
    • 支援互動探索

自我檢核類別分佈用長條圖、趨勢用折線圖；TF-IDF 排除常見詞；異常偵測典型為信用卡詐騙；品牌名稱比對用 NER。

第六章 大數據在人工智慧之應用

資料進入 AI：機器學習流程、鑑別式與生成式應用、隱私合規。

L224016.1 大數據與機器學習開啟 →
  • 5V 對機器學習的衝擊
    • Volume：Mini-Batch、分散式
    • Variety：多模態對齊與融合
    • Velocity：串流、增量學習
    • Veracity：漂移偵測（KS、KL）
    • Value：特徵選擇、主動學習
    • 數據漂移 vs 概念漂移
  • 模型訓練加速
    • 資料並行／模型並行／混合並行
    • 混合精度（FP32 + FP16）
    • 梯度累積與壓縮
    • 預訓練 + 微調
    • 避免災難性遺忘
  • 端對端流程 MLOps
    • 資料整合與管線
    • 訓練驗證：MLflow、W&B
    • 部署：Batch／Online／Streaming
    • 監控與自動重訓
L224026.2 大數據在鑑別式 AI 的應用開啟 →
  • 常見應用情境
    • 金融：信用評分、反洗錢
    • 零售：流失預測、推薦
    • 客服：情感分析
    • 醫療：疾病診斷

  • 輸入資料型態
    • 結構化
    • 半結構化（解析、展平）
    • 非結構化（特徵萃取）
    • 多模態（特徵級融合）
  • 資料標註策略
    • 人工標註
    • 弱監督式標註
    • 群眾外包
    • 主動式學習

    • 更新頻率不一
    • 品質不均影響推論
