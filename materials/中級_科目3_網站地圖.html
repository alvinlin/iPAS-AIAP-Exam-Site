第三章 機器學習基礎數學

數學地基：機率統計處理不確定性、線性代數表示資料、數值優化求解參數。

L231013.1 機率/統計之機器學習基礎應用開啟 →
  • 資料與隨機變數的機率表示
    • 條件機率分佈 P(Y｜X)
    • 離散型：PMF，總和 = 1
    • 連續型：PDF，積分求 P(a≤X≤b)
    • 伯努利、二項、泊松
    • 常態、均勻、指數（無記憶性）、卡方
    • 分佈即先驗假設
  • 條件機率與貝氏推論
    • P(A|B) = P(A∩B) / P(B)
    • 貝氏定理：P(B|A)·P(A) / P(B)
    • 先驗、似然、邊際、後驗
    • 應用：貝氏分類器、VAE、HMM
  • 假設檢定與統計推論
    • 參數估計 vs 假設檢定
    • 點估計與 95% 信賴區間
    • 檢定五步驟：H₀／H₁ → 決策
    • 顯著水準 α = 型一錯誤機率
    • p < α 拒絕虛無假設
  • 統計量與機器學習中的應用
    • 期望值：預測基準
    • 變異數／標準差：判斷需否標準化
    • 偏態：對數或 Box-Cox 轉換
    • 峰度：尖峰、厚尾
    • 直方圖、箱型圖、QQ-plot
L231023.2 線性代數之機器學習基礎應用開啟 →
  • 向量與矩陣表示
    • 點積：投影與相似度
    • L2 範數：向量長度
    • 矩陣乘法、轉置
    • 求逆與偽逆
    • 線性迴歸 ŷ = Xθ
  • 線性變換與特徵空間
    • 縮放、旋轉、剪切、投影
    • 特徵空間
    • 嵌入層：類別轉連續向量
    • LDA、Autoencoder 投影壓縮
  • 矩陣分解與維度簡化
    • 特徵值分解 A = QΛQᵀ（PCA）
    • SVD X = UΣVᵀ（推薦、LSA）
    • NMF X ≈ WH（主題建模）
    • 降維：去雜訊與共線性
  • 最小平方估計與線性迴歸
    • OLS：誤差平方和最小
    • 幾何觀點：投影至平面
    • 離群點會扭曲擬合
L231033.3 數值優化技術與方法開啟 →
  • 最佳化問題的基本結構
    • 目標函數（損失／成本函數）
    • 決策變數：權重與偏差
    • 可行域（參數空間）
    • 凸函數必得全域最佳解
    • 非凸：局部最小值與鞍點
  • 損失函數與學習目標
    • 迴歸：MSE、MAE、Huber
    • 分類：交叉熵、對比損失
    • Focal Loss：資料不平衡
    • 排序損失、重建損失
  • 常見優化演算法與比較
    • GD／SGD／Mini-batch SGD
    • Momentum：累積梯度方向
    • Adagrad：學習率過度衰減
    • RMSprop：滑動平均
    • Adam：一階＋二階動量
  • 收斂判準與訓練穩定性
    • 損失變化低於 ε、梯度趨近零
    • 學習率過高致震盪發散
    • 學習率調度、Early Stopping
    • 梯度裁剪、批次正規化

三大學習類型、常見演算法，到深度學習架構與框架。

L232014.1 機器學習原理與技術開啟 →
  • 機器學習的基本結構
    • 輸入資料與特徵空間
    • 任務目標與標籤型態
    • 模型與假設空間
    • 訓練集／驗證集／測試集
  • 三大學習類型
    • 監督式：分類、迴歸
    • 非監督式：聚類、降維、關聯規則
    • 強化式：最大化長期累積報酬
    • MDP：Agent、State、Action、Reward
    • 離散 vs 連續動作空間
L232024.2 常見機器學習演算法開啟 →
  • 監督式學習 — 迴歸任務
    • 線性迴歸（對離群值敏感）
    • Lasso（L1，可特徵選擇）vs Ridge（L2）
    • SVR：ε-tube
    • 決策樹迴歸（分段常數）
    • 隨機森林、梯度提升、XGBoost／LightGBM
    • 附圖：Level-wise vs Leaf-wise（指引 4-23）
  • 監督式學習 — 分類任務
    • 邏輯迴歸：sigmoid 輸出機率
    • SVM：最大化間隔、核函數
    • 決策樹：基尼、資訊增益
    • KNN（需特徵縮放）、樸素貝氏
    • Bagging 降變異、Boosting 降偏差
    • OvR、Softmax、OvO
  • 非監督式學習
    • 分群：k-means、階層式、DBSCAN
    • 降維：PCA、t-SNE、UMAP
    • 關聯規則：Apriori、FP-Growth
    • 支持度、信賴度、提升度（Lift）
    • 異常偵測：孤立森林、One-Class SVM
L232034.3 深度學習原理與框架開啟 →
  • 深度學習基本概念
    • 人工神經元：Z = Σwx + b
    • 感知器無法解 XOR
    • 激活函數引入非線性
    • 前向傳播 vs 反向傳播（連鎖律）
    • 過擬合：L1、L2、Dropout、早停
  • 深度學習模型架構
    • MLP：全連接前饋
    • CNN：卷積、池化、權重共享
    • RNN：梯度消失 → LSTM、GRU
    • Transformer：自注意力 Q/K/V、位置編碼
    • BERT（編碼器）vs GPT（解碼器）
    • 生成式：自編碼器、GAN
  • 深度學習主流框架
    • TensorFlow／Keras（Google）
    • PyTorch：動態計算圖、Autograd
    • JAX：函數式數值計算
    • MXNet（AWS）、PaddlePaddle

第五章 機器學習建模與參數調校

完整建模流程：資料準備、模型選擇、訓練評估、調校與壓縮。

L233015.1 數據準備與特徵工程開啟 →
  • 數據清理
    • 缺失值：刪除、填補、缺失指標
    • 異常值：Z 分數、IQR、Isolation Forest
    • 重複樣本與一致性
    • 樹模型對缺值容忍度較高
  • 特徵選擇與降維方法
    • Filter：統計量篩選
    • Wrapper：RFE、前向／後向選擇
    • Embedded：樹重要性、Lasso
    • PCA、LDA、t-SNE／UMAP、SVD
  • 特徵轉換與資料標準化
    • Min-Max、Z-score、Robust Scaling
    • 對數、Box-Cox／Yeo-Johnson
    • Label／One-hot／Target Encoding
    • 週期特徵 sin/cos 編碼
  • 資料增強 (Data Augmentation)
    • 圖像：翻轉、旋轉、裁剪
    • 文字：同義字替換
    • 時序：Jittering、窗口裁切
    • 表格：SMOTE
  • 特徵工程策略
    • 依任務類型設計
    • 依模型性質調整
    • 欄位合成、統計聚合
    • 滯後值 lag、移動平均
L233025.2 模型選擇與架構設計開啟 →
  • 任務類型與模型特性配對
    • 分類：樹、SVM、神經網路
    • 聚類：K-means vs DBSCAN
    • 降維：PCA vs 自編碼器
    • 時序：LSTM、TCN、ARIMA
  • 資料規模與模型選擇
    • 小型：線性、決策樹、Lasso/Ridge
    • 中型：隨機森林、XGBoost
    • 大型：深度模型、GPU 分散式
  • 模型解釋性需求
    • 高解釋性：線性、淺層決策樹
    • 低解釋性：集成、深度網路
    • SHAP、LIME、PDP
  • 運算資源與實務部署限制
    • 邊緣裝置：剪枝、量化
    • 即時推論：注意延遲
    • 模型蒸餾、caching
    • 偏差-變異權衡
    • 附圖：偏差-變異權衡（指引 5-16）
L233035.3 模型訓練、評估與驗證開啟 →
  • 模型訓練流程與策略
    • 資料分割與 K-fold
    • Batch GD／SGD／Mini-batch
    • 學習率衰減與預熱
    • 早停：Patience、Min Delta
    • TensorBoard、MLflow
  • 評估指標與模型效果衡量
    • 混淆矩陣 TP／FP／FN／TN
    • Precision = TP/(TP+FP)
    • Recall = TP/(TP+FN)
    • F1、ROC-AUC
    • MSE、MAE、RMSE、R²
    • 附圖：ROC 曲線（指引 5-22）
  • 交叉驗證 (Cross-Validation)
    • K-fold（K = 5 或 10）
    • Stratified K-fold：分類預設
    • LOOCV：偏差最小、成本極高
    • Repeated K-fold
L233045.4 模型調整與優化開啟 →
  • 超參數調校 (Hyperparameter Tuning)
    • 學習率、批次大小
    • 網路深度與寬度
    • Softmax、ReLU、Sigmoid、Tanh
    • SGD、Momentum、Adagrad、Adam
    • 正則化係數 λ
  • 正則化技術與模型穩定化
    • L1（Lasso）：權重歸零
    • L2（Ridge）：權重不壓到零
    • Elastic Net：L1 + L2
    • Dropout（常見 p = 0.5）
    • Early Stopping（patience）
  • 資料增強與重取樣
    • 影像、文字、音訊增強
    • 過採樣（SMOTE）
    • 欠採樣
    • 類別權重調整
  • 模型壓縮與加速技術
    • 知識蒸餾：教師 → 學生
    • 剪枝：結構化 vs 非結構化
    • 量化：FP32 → INT8、QAT
    • 混合精度訓練 FP16 + FP32
